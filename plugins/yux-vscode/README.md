# yux-vscode

yux 语言的 Visual Studio Code 扩展，提供语法高亮、代码补全和导航支持。

## 功能

### 语法高亮

支持 yux 语言的关键字、类型、字符串、数字、注释等语法高亮。同时在 Markdown 文件中支持 yux 代码块高亮。

### 代码补全

#### 关键字

| 关键字 | 说明 |
|--------|------|
| `fn` | 函数声明 |
| `ret` | 返回语句 |
| `if` / `elif` / `else` | 条件语句 |
| `true` / `false` / `null` | 布尔值和空值 |
| `var` / `val` / `cval` | 变量声明 |
| `struct` | 结构体声明 |
| `loop` / `break` | 循环语句 |

#### 基本类型

| 类型 | 说明 |
|------|------|
| `i8` / `i16` / `i32` / `i64` | 有符号整数 |
| `u8` / `u16` / `u32` / `u64` | 无符号整数 |
| `f32` / `f64` | 浮点数 |
| `bool` | 布尔类型 |

#### 泛型类型

| 类型 | 说明 |
|------|------|
| `Ref<T>` | 引用类型 |
| `Rc<T>` | 堆对象类型 |
| `Ptr<T>` | 原始指针类型 |
| `Array<T>` | 动态数组类型 |

#### 内置函数

- `print` - 打印输出
- `println` - 打印输出并换行
- `to_<type>` - 类型转换方法（如 `to_i32`, `to_f64` 等）

#### 代码片段

| 片段 | 说明 |
|------|------|
| `fn` | 函数声明模板 |
| `fn-expr` | 函数表达式模板 |
| `if` / `if-else` / `if-elif-else` | 条件语句模板 |
| `struct` | 结构体声明模板 |
| `impl` | 结构体实现模板 |
| `var` / `val` / `cval` | 变量声明模板 |
| `ret` | 返回语句模板 |
| `array` / `array-lit` | 数组模板 |
| `loop` | 循环模板 |

#### 智能补全

- 文档中的函数、变量、结构体自动补全
- 成员访问补全（`.` 后自动提示字段和方法）

### 导航功能

- **跳转到定义**：支持函数、变量、结构体、字段、方法的定义跳转
- **查找引用**：查找符号在当前文档中的所有引用
- **文档符号**：在大纲视图中显示当前文档的符号结构

### 编辑支持

- 括号自动配对：`{}` `[]` `()` `""`
- 自动缩进
- 代码折叠
- 注释切换（`/` 为行注释）

## 安装

1. 下载 `.vsix` 文件
2. 在 VS Code 中按 `Ctrl+Shift+P`，输入 `Install from VSIX`
3. 选择下载的文件安装

## 开发

```bash
# 安装依赖
pnpm install

# 编译
pnpm run compile

# 打包
pnpm run build
```

按 `F5` 启动调试，会打开一个新的 VS Code 窗口用于测试扩展。
