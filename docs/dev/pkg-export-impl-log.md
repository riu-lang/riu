# pkg 导出与定向开放实施记录

规范：§10.2.4；本轮实现 v0.22 的解析、加载与包边界检查，未改动 g4。

## 解析与加载

- `parsePkgFileAt` 共用解析 `as` / `to`，非法行报 E5020；导出项保留源行号。
- `Yux::visiblePkgItems` 统一计算调用方可见清单。包内按源文件所在目录判断；子目录不属于同包。包外仅公开项及匹配 `to` 的项可见。
- `Yux::resolvePkgPath` 按段将导出名转换为源模块名，逐层检查包边界。源模块身份保留给加载、类型归属和代码生成，调用方别名保持源码书写形式。
- `use`、包通配展开、包孩子预加载、函数点链、类型限定路径共用上述规则。未导出项和改名后的源名报 E5018。
- `to` 目标检查项目源树及已加载依赖；不存在报 E5019，定位到对应 `pkg` 行。此检查不主动加载目标，避免制造循环依赖。
- 同包通过包别名访问自身时复用当前 FileNode；通配展开跳过自身，避免重复注入和伪循环依赖。
