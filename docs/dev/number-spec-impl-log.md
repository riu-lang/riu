# Number spec 实施记录

## 目标

为 SDK 内置数字提供可用于泛型边界的 `Number` spec，并删除 `num.yux` 中每个数字类型重复的借用参数运算 / 比较声明。

## 设计与实现

- `Number` 声明 `MIN` / `MAX` 两个 `#Cval #Inline` 静态字段契约、固定数值转换、按值算术 / 比较与 `neg`。`to_bool`、`to_string`、位运算和非公共转换不进入该契约。
- 算术和比较方法不设默认体。`$ + other` / `$ == other` 会通过操作符分发回到 `plus` / `eq`，因此必须由数字 `#Builtin` 按值方法直接实现。
- spec 方法返回类型中的 `Self` 会在边界查找和单态化时替换为当前类型形参 / 实参；泛型 AST 的已解析类型也会应用当前替换帧，避免跨实例污染。
- `T::MIN` / `T::MAX` 在 `<T : Number>` 中通过边界的静态字段表解析，单态化后使用具体数字类型的内联常量。
- `SpecImplChecker` 把静态字段纳入 `#Impl` 穷尽性校验；缺失、类型不符或必需的 `#Cval/#Inline` 属性缺失均报 E1141。
- 含静态字段的 spec 在 `.decl` 回写时保留源码骨架，与含默认体的 spec 走同一路径，防止 SDK / 跨模块加载丢失字段注解与契约。

## 验证

- SDK 算术测试覆盖 `i32` / `f64` 的 `Number` 算术、比较、`T::MIN` / `T::MAX`，以及 `u8 -> i64` 泛型转换。
- 诊断用例覆盖 `#Impl(Number)` 缺少边界常量时的 E1141。
