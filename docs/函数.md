# 函数

本文档介绍 yux 语言中函数的定义和使用。

## 函数定义

```yux
; 无参数
fn nop() {

}

; 表达式作为函数体
fn add(a i32, b i32) i32 = a + b

; 标准写法
fn sub(a i32, b i32) i32 {
  ret a + b
}

; 私有函数（_开头）
fn _pri_fn() {

}
```

## 返回语句

```yux
; 返回值
fn add(a i32, b i32) i32 {
  ret a + b
}

; 空返回（返回 void）
fn early_exit(flag bool) {
  if flag {
    ret;
  }
  println(123.to_string())
}
```

**规则：**
- `ret` 用于返回值
- `ret;` 用于 void 函数提前返回，必须尾随 `;`

## 泛型函数

```yux
; 定义泛型函数
fn <T> identity(x T) T = x

fn <T> add(a T, b T) T = a + b

; 显式指定类型参数调用（turbofish 形式：`name:<T>(args)`）
val a i32 = identity:<i32>(42)
val b i64 = identity:<i64>(100)

; 类型推断调用
val c i32 = identity(999)
val d i32 = add(1, 2)

; 多类型参数
fn <K, V> make_pair(k K, v V) Pair<K, V> {
  ret make_pair:<K, V>(k, v)
}
```

> **为什么要写 `:<T>` 而不是 `name<T>(args)`？**
> `<` `>` 与比较运算符复用 token，`Generic<T>(args)` 会被解析成 `(Generic < T) > (args)` 的比较表达式。turbofish 前缀 `:` 让解析器明确进入泛型实例化分支，避免歧义。无需显式类型参数时仍可直接写 `identity(999)`，由编译器推断。

## 函数参数

### 参数组

多个连续的同类型参数可以共享类型声明：

```yux
; 参数组写法
fn add(a, b i32) i32 = a + b

; 等价于标准写法
fn add(a i32, b i32) i32 = a + b

; 混合使用
fn calc(a, b i32, c f64) f64 {
  ret (a + b).to_f64() + c
}

; 多个参数组
fn multi(a, b i32, x, y f64) {
  ; ...
}
```

### 值传递

```yux
fn double(x i32) i32 {
  ret x * 2
}
```

### 引用传递

```yux
fn modify(p Ref<Point>) {
  p.x = 10.0
}
```

### 自动取引用

当函数参数为 `Ref<T>` 时，可传入 `T` 类型的值，自动取引用：

```yux
struct Point {
  x f64
  y f64
}

Point {
  fn Point(x f64, y f64) {
    $.x = x
    $.y = y
  }
  
  fn move_to(dx f64, dy f64) {
    $.x = $.x + dx
    $.y = $.y + dy
  }
}

fn main() {
  var p = Point(1.0, 2.0)
  p.move_to(1.0, 1.0) ; 自动取引用
}
```

## 关键字

yux 中的关键字：
- `fn` - 定义函数
- `var` - 可变变量
- `val` - 不可变变量
- `cval` - 全局常量
- `if`, `elif`, `else` - 条件分支
- `ret` - 返回值
- `break` - 跳出循环
- `null` - 空指针
- `true`, `false` - 布尔值
- `loop` - 循环
- `struct` - 定义结构体
- `use` - 模块导入
- `extern` - 外部声明块
