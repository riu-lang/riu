# 函数

本文档介绍 yux 语言中函数的定义和使用。

## 函数定义

```yux
; 无参数
fn nop() {

}

; 表达式作为函数体
fn add(a i32, b i32) i32 = a + b

; 标准写法
fn sub(a i32, b i32) i32 {
  ret a + b
}

; 私有函数（_开头）
fn _pri_fn() {

}
```

## 返回语句

```yux
; 返回值
fn add(a i32, b i32) i32 {
  ret a + b
}

; 空返回（返回 void）
fn early_exit(flag bool) {
  if flag {
    ret;
  }
  println(123)
}
```

**规则：**
- `ret` 用于返回值
- `ret;` 用于 void 函数提前返回，必须尾随 `;`

## 泛型函数

```yux
; 定义泛型函数
fn identity<T>(x T) T = x

fn add<T>(a T, b T) T = a + b

; 显式指定类型参数调用（turbofish 形式：`name:<T>(args)`）
val a i32 = identity:<i32>(42)
val b i64 = identity:<i64>(100)

; 类型推断调用
val c i32 = identity(999)
val d i32 = add(1, 2)

; 多类型参数
fn make_pair<K, V>(k K, v V) Pair<K, V> {
  ret make_pair:<K, V>(k, v)
}
```

> **为什么要写 `:<T>` 而不是 `name<T>(args)`？**
> `<` `>` 与比较运算符复用 token，`Generic<T>(args)` 会被解析成 `(Generic < T) > (args)` 的比较表达式。turbofish 前缀 `:` 让解析器明确进入泛型实例化分支，避免歧义。无需显式类型参数时仍可直接写 `identity(999)`，由编译器推断。

## 函数参数

### 参数组

多个连续的同类型参数可以共享类型声明：

```yux
; 参数组写法
fn add(a, b i32) i32 = a + b

; 等价于标准写法
fn add(a i32, b i32) i32 = a + b

; 混合使用
fn calc(a, b i32, c f64) f64 {
  ret (a + b).to_f64() + c
}

; 多个参数组
fn multi(a, b i32, x, y f64) {
  ; ...
}
```

### 单行 / 多行写法

形参较多时可以折成多行。`(` 之后、`,` 之后、`)` 之前都允许换行；末参可尾随 `,`。

```yux
; 单行
fn add(a i32, b i32) i32 = a + b

; 多行（推荐每参一行 + 尾随 `,` + `)` 单独成行）
fn make_user(
  name String,
  age i32,
  email String,
) User {
  ; ...
}
```

调用时同样支持：

```yux
val u = make_user(
  "alice",
  30,
  "a@x.io",
)
```

> 格式化器约定：1 个参数强制单行；多参默认单行，超 120 列时折成多行。

### 值传递

```yux
fn double(x i32) i32 {
  ret x * 2
}
```

### 参数可变性

形参在函数体内**默认不可重赋**（隐含 `val` 风）：

```yux
fn f(a i32) i32 {
  ; a = 10        ; 错误 E3093：不可重赋形参
  ret a + 1
}
```

如需"深不可变"形参（连字段写、子字段写都禁），加 `#Frozen` 注解：

```yux
fn dump(#Frozen s String) {
  println(s)
  ; s.push("x")   ; 错误：String.push 不是 #Const fn，不能在 #Frozen 形参上调
}

; 参数组同样可标 #Frozen，作用于组内所有名字
fn cmp(#Frozen a, b Config) bool { ... }
```

`#Frozen` 形参不能被传给非 `#Frozen` 受方位（避免"借出去就被偷写"，错误码 E3107）；如需取一份 owned 副本以脱 const，调内置 `copy_of:<T>(x T&) T`。

### `#Const fn` 编译期常量函数

把函数标 `#Const` 表示"该函数对外部状态无副作用"：

```yux
#Const
fn add(a i32, b i32) i32 = a + b

#Const
fn square(x i32) i32 {
  val k = x        ; 局部 var / val / cval 允许
  ret k * k
}
```

`#Const` 函数体禁止：写 `$.f`、写参数字段（错误码 E3110）、写非 `cval` 全局、调任何非 `#Const` 函数（错误码 E3111）。允许读 `$` / 参数 / 全局 `cval` / 全局 `val`，可调其它 `#Const` 函数。

### 引用传递

```yux
fn modify(p Ref<Point>) {
  p.x = 10.0
}
```

### 自动取引用

当函数参数为 `Ref<T>` 时，可传入 `T` 类型的值，自动取引用：

```yux
struct Point {
  x f64
  y f64
}

Point {
  fn Point(x f64, y f64) {
    $.x = x
    $.y = y
  }
  
  fn move_to(dx f64, dy f64) {
    $.x = $.x + dx
    $.y = $.y + dy
  }
}

fn main() {
  var p = Point(1.0, 2.0)
  p.move_to(1.0, 1.0) ; 自动取引用
}
```

## 函数值与 lambda

yux 中的函数也是一等值，可作为变量、形参、返回值传递。函数类型字面量 `fn(T)R` 与 lambda 字面量 `(x i32) i32 => x + 1` / `{ a, b => a + b }` 由独立文档 [Lambda 与闭包](Lambda与闭包.md) 详述，包括：

- 函数类型 `fn(T)R` / `fn?(T)R` 的写法与结构等同；
- lambda 形态（括参表达式 / 单参省括号 / 块形含 0 参块）；
- 尾随 lambda 调用糖 `f(arr) { x => ... }`；
- 闭包捕获语义（标量值复制 / 堆句柄 retain / `T&` 透传 / 方法内 `$`）；
- 捕获写禁、含 `T&` 捕获不可逃逸、返回 `T&` 溯源等约束。

## 关键字

yux 中的关键字（以 `src/yuxLexer.g4` 为准）：

| 关键字 | 用途 |
|---|---|
| `fn` | 定义函数 |
| `var` / `val` | 可变 / 不可变变量 |
| `cval` | 全局常量 |
| `if`, `elif`, `else` | 条件分支 |
| `loop` | 无限循环（用 `break;` 退出） |
| `ret` | 返回值 |
| `break` | 跳出循环（语句形式必须写 `break;`） |
| `struct` | 定义结构体 |
| `enum` | 定义枚举 |
| `match` | 模式匹配 |
| `try` / `catch` | 错误处理（见 `docs/错误处理.md`） |
| `use` | 模块导入 |
| `extern` | 外部声明块 |
| `draft` | 草案 / 占位声明 |
| `null` | 空指针字面量 |
| `true` / `false` | 布尔字面量 |

特殊记号（不是关键字但语法保留）：

- `$` —— 当前方法的实例（相当于其它语言里的 `self` / `this`），仅在结构体方法体内有效。
- `_` 前缀 —— 标识符以 `_` 开头表示"模块私有"（见 `docs/模块系统.md` §可见性）。

类型名 `i32` / `f64` / `bool` / `String` / `Array<T>` / `Rc<T>` / `Weak<T>` / `Nullable<T>` / `StringBuilder` / `Ptr` 等是 `yux.core` 提供的**内置类型**，不是关键字 —— 它们与普通 ID 同一词法类别，仅在语义层有特殊含义。
