# 23 结构体字段默认值

| | |
|---|---|
| 状态 | 实施中 |
| 开 | 2026-09-22 |
| 旧档 | §7.3.1.3 / §7.3.3.2 明确「语言不提供字段默认值」。[#21](21-ptr-generic.md) 是**类型形参**默认（`T=()`），不是字段。调用方：[#6](6-cond-compile.md) 注解 struct 缺省实参 |

不绑版本。类 C++ 默认成员初值：`field T = expr`。给注解 `#Anno struct { repeatable bool = false }` 当前置；本身是普通 struct 能力，不只注解。

bnf `filedDecl` **已有**可选 `= expr`。builder 建了再 `(void)init` 丢掉。本条主要是翻 spec + 接到 `Self { }` / E3125，不一定改产生式。

## 提议

实例字段可写默认表达式，字面量可省略该字段，缺的用默认补上（C++ in-class initializer）。没有「默认构造函数」：仍走 `Self { }` / `Type { }`，只是不必列全。

```riu
struct Point {
  x i32 = 0
  y i32 = 0
}

fn origin() Point = Point { }          ; 两字段都用默认
fn onX(n i32) Point = Point { .x = n } ; y 用 0
```

注解侧（#6）依赖本条：

```riu
#Anno
struct Anno {
  repeatable bool = false
  on Array<AnnoType> = []     ; 形态见 #6，此处只说明要默认
}
```

裸 `#Anno` 不再特判，缺的字段走默认。

## 评估

### 现状

| | 现行 |
|---|---|
| 语法 | `filedDecl ::= … ID type ( '=' expr )?` 已收 |
| builder | 实例字段 `init` 丢弃；`#Static` 字段必须有 init（E3150） |
| spec | §7.3.3.2 **禁止**有名字段隐式默认；`Self { }` 必须列全（E3125）；`_` 丢弃槽零填是唯一例外 |
| 类型默认 | #21 `struct Foo<T=i32>`，使用点补实参，与字段无关 |

### 赞成

- `#6` 裸 `#Anno` / 可选注解字段不用编译器特判。
- 与 C++ 默认成员初值同形，构造通道仍是字面量，不引入 `Point()`。
- 语法槽已在，破坏面小：今天写 `x i32 = 0` 能 parse，只是默认不生效。

### 反对

- 翻 §7.3.3.2 是语义变化：以前「列全」是不漏 init；有默认后漏写变成静默用默认。

## 决定

- 日期：2026-09-23
- 结论：语义已定（状态仍 **提议**，未改 `待实施`）。默认必须 const；声明处求一次；`#Val` / `#Frozen` 可带默认；E3129 只计无默认有名字段；范围仅实例字段。
- 理由：#6 注解字段本来就要 const；声明处嵌入避免每个省略点再跑；构造通道仍是字面量，`#Val` / `#Frozen` 的构造期放行覆盖默认代入；简写按「还要手填几个」计。

## 规范要点

实施依据（未改 spec 正文）：

- 语法：沿用 `filedDecl` 的 `= expr`；无新 token。`expr` 必须 const-eval（与 `#Cval` 初值同一套）。
- **求值**：声明处求一次，常量嵌入类型；每个省略点用同一份，不再求。
- `Self { }` / `Type { }`：未写出的有名字段若有默认则代入该常量；无默认仍 E3125。写出的字段覆盖默认。
- 不引入无参构造 / `Type()`。
- `#Val` / `#Frozen` 实例字段可以有默认。代入等价于构造位写出 `.f = <嵌入常量>`（§7.1.4.3 放行）；构造完成后限定照旧。
- **单字段简写** `Type{ expr }` / E3129：只计**无默认**的有名实例字段（`_` / `#Static` 仍不计）。恰好 1 个无默认有名字段时简写填那个字段，有默认的其余字段走默认。0 或 ≥2 个无默认有名字段 → E3129。全字段都有默认时 `Type { }` 合法，`Type{ expr }` 仍 E3129。
- **仅实例**：spec 契约字段（`#Cval` `#Inline` 静态等）不在本条。`#Static` 字段现状不变（本来就要 `=`，那是静态初值不是本条默认）。
- 不定长默认用 `Array<T> = []`；定长仍 `[T * N]`。
