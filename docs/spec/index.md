# riu 语言规范（草案）

> riu（发音通 U，非英语）。源文件 `.ut`（U Text），声明缓存 `.ud`。
> 本目录是 riu 的**规范级**文档，与 `docs/*.md`（用户教程）并列。
> 教程关心"怎么用"，规范关心"语义如何被定义"。

**状态**：草案（v0.x）。当与编译器实现冲突时以 `riu/ast/riu*.g4` 与 `riu/**/*.cpp` 为准，并回写本规范。

## 编号与用语约定

- 每章以 §N 编号；章内条款 §N.M.K，便于跨文件引用（如 §8.3.2）。
- 规范用语：
  - **应当 (shall)** / **不得 (shall not)**：硬性要求；违反则程序非法。
  - **应该 (should)**：推荐；违反不致非法但需理由。
  - **可以 (may)**：可选行为。
- 标 *informative* 的段落或示例不属规范本体，仅作说明。
- 每章末尾 *Open Issues* 为历史残留；**新未决项开 [`prop/`](prop/)**，不要往 Open Issues 堆。
