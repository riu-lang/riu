# 命令行工具

所有 exe 放在 `build/windows/x64/<mode>/bin/`，**互相独立**。均支持 `--version` 和 `-h`/`--help`。

## 可执行文件一览

| exe | 用途 | 依赖 LLVM | 用户直接调用 |
|-----|------|-----------|-------------|
| `yux` | 主编译器：`build`(项目编译)、`test`(运行测试)、`format`(格式化) | 是 | 是 |
| `yux-lsp` | LSP 服务器，编辑器插件通过 stdio 接入；构建后自动复制为 `yux-lsp-claude` | 否 | 否（插件自动启动） |
| `yux-ast` | 转储 ANTLR4 parse tree，仅词法+语法，不做 AST/语义/codegen | 否 | 是 |
| `yux-check` | 快速语义检查（阶段 0）：parse→AST→SemaPass，0 LLVM；支持单文件 + `test` 子命令批量诊断 | 否 | 是 |
| `yux-test-runner` | 测试运行器，由 `yux test` 内部 spawn 加载 DLL 执行 #Test | 否 | 否（`yux test` 自动调） |

## yux

```
yux [OPTIONS] SUBCOMMAND

OPTIONS:
  -h, --help              Print this help message and exit
      --version           Print version and exit
      --emit-ir           Emit LLVM IR to .ll file
      --emit-ir-dir TEXT  Output directory for .ll files (default: build/)
      --warn TEXT         Treat code as warning (Exxxx; can repeat)
      --allow TEXT        Treat code as note (Exxxx; can repeat)
      --deny TEXT         Treat code as error (Exxxx; can repeat)
      --Werror            Treat all warnings as errors
  -d, --debug             Output compilation IR debug information

SUBCOMMANDS:
  build                   Build project (must run at project root containing yux.toml)
  test                    Run #Test functions via DLL test runner
  format                  Format a .yux source file
```

### yux build

```
yux build [OPTIONS] [name]

POSITIONALS:
  name TEXT               Project name (optional; must match `name` in yux.toml when given)

OPTIONS:
  -h, --help              Print this help message and exit
      --emit-ir           Emit LLVM IR to .ll file
      --emit-ir-dir TEXT  Output directory for .ll files (default: build/)
      --test              Build test executables for *.test.yux into build/tests/
      --test-mod TEXT     Build only the specified test module (e.g. yux.core.array)
  -d, --debug             Output compilation IR debug information
      --warn TEXT         Treat code as warning (Exxxx; can repeat)
      --allow TEXT        Treat code as note (Exxxx; can repeat)
      --deny TEXT         Treat code as error (Exxxx; can repeat)
      --Werror            Treat all warnings as errors
```

### yux test

```
yux test [OPTIONS]

OPTIONS:
  -h, --help              Print this help message and exit
  -v, --verbose           Print captured stdout/stderr for every test (default: only on failure)
      --threads INT       Thread count (default: CPU cores)
      --test-mod TEXT     Build and run only the specified test module (e.g. yux.core.array)
  -d, --debug             Output compilation IR debug information
```

流程：`yux build --test`（复用缓存，只重编变化的文件）→ 并行 spawn `yux-test-runner` 子进程，每个子进程加载一个 DLL、顺序跑其中测试、SEH 包裹异常。
测试写在 `*.test.yux`（**不能**挂在普通 `.yux`），断言用 `assert_eq`/`assert_true`/`fail`。SDK 测试集在 `sdk/yux/src/yux/core/*.test.yux`。
**摘要行**：每个 DLL 输出末尾必有一行 `<dll>: X passed, Y failed, [T]`。如果某个 DLL 输出末尾**没有**摘要行，就是进程意外退出（崩溃/被强制终止/死循环）。

### yux format

```
yux format [OPTIONS] [file]

POSITIONALS:
  file TEXT               Input .yux file to format

OPTIONS:
  -h, --help              Print this help message and exit
  -i, --in-place          Edit file in place
      --stdin             Read from stdin instead of file
      --line-width INT    Line width threshold (default: 120)
```

## yux-ast

```
yux-ast [OPTIONS] input

POSITIONALS:
  input TEXT REQUIRED     Input .yux file

OPTIONS:
  -h, --help              Print this help message and exit
      --version           Print version and exit
  -o, --output TEXT       Output file (default: stdout)
      --oneline           Print tree on a single line (default: pretty multi-line)
```

## yux-check

```
yux-check [OPTIONS] [input] [SUBCOMMAND]

POSITIONALS:
  input TEXT              Input .yux file

OPTIONS:
  -h, --help              Print this help message and exit
      --version           Print version and exit

SUBCOMMANDS:
  test                    Batch test .yux files with `; check:` annotations
```

### yux-check test

诊断用例在 `tests/check-cases/`，行尾 `; check: EXXXX` 注解，错误码 + 行号精确匹配。

## 构建缓存

`PkgCacheRegistry`：基于编译器指纹 + 源文件 mtime/size 判断 obj 是否新鲜。`yux build` 与 `yux test` 共用同一套缓存，**无需手动删除**——编译器重编后指纹变化自动全体作废。
