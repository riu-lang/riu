# 基础语法

本文档介绍 yux 语言的基础语法规则。

## 注释

```yux
; 顶行注释，缩进也可
fn some() {
  ; 也可缩进
  println(123) ; 尾随注释
}
```

**说明：**
- 顶行注释：`;` 位于行首（可以有缩进）
- 尾随注释：空格 `;` 开头（代码行或空行后）

## 空格规则

- 关键字后必须有空格
- 二元运算符两边必须有空格
- `()` `[]` 内部无空格
- `,` 后有空格

```yux
; 正确
fn add(a i32, b i32) i32 = a + b
let arr = [1, 2, 3]

; 错误
fn add(a i32,b i32)i32=a+b ; 缺少空格
let arr = [ 1,2,3 ]        ; 括号内多余空格
```

## 块与作用域

yux **没有** C / Rust 风格的独立裸 `{ }` 语句块（单独一对花括号不是语句，内部不会执行）。  
但 `if` / `elif` / `else` / `loop` / `match` arm / `try`·`catch` / 函数体 / 块形 lambda 的 **`statementBlock` 是词法作用域**（§5.7.1）：块内 `let`（及 `loop` init 变量）出块不可见；内层可遮蔽外层同名。

| 结构 | 示例 |
|------|------|
| 函数体 | `fn f() { ... }` |
| if / elif / else 体 | `if x > 0 { ... } else { ... }` |
| loop 体（含 init） | `loop i = 0 { ... }` |
| match 体 | `match e { ... }` |
| struct 字面量 | `Point { .x = 1 .y = 2 }`（非语句作用域） |
| 块形 lambda | `{ a, b => a + b }` |
| try 体 / catch 体 | `try { ... } catch e E { ... }` |

```yux
; ❌ 错误：裸 `{ }` 不是语句块
fn main() {
  let x i32 = 1
  {                      ; 不是作用域，也不会执行
    let y i32 = 2
  }
}

; ✅ if / loop 体有块作用域
fn demo() i32 {
  let x i32 = 1
  if true {
    let x i32 = 2        ; 遮蔽外层 x
    ret x                ; 2
  }
  ret x                  ; 1
}

fn count() {
  loop i = 0 {
    if i >= 3 {
      break;
    }
    i = i + 1
  }
  ; 此处不可见 i
}
```

## 变量声明

yux 用 `let` 作为**唯一**变量声明引入符。默认浅不可变；要可变就在 `let` 前加 `#Mut` 注解。

```yux
; 默认（浅不可变）—— 旧 val
let a i32 = 10
; a = 20  ; ❌ 错误：默认 let 不可重赋

; 可变 —— 旧 var
#Mut let b i32 = 100
b = 200    ; ✅

; 类型推断
let c = 123
let d = 3.14
let e = true

; #Mut 允许"先声明后赋值"（旧 var x T 形态）
#Mut let x i32
x = 42

; 默认 / #Cval / #Frozen 必须带初值；
; #Mut 也允许带初值，常见写法仍是 #Mut let y = 1
```

**说明：**
- `let`：默认浅不可变，至多赋值一次（带初始化即唯一赋值）
- `#Mut let`：可变变量，可重新赋值；唯一允许"先声明后赋值"的形态（局部）。全局位 `#Mut` 也允许，但必须带初值（见下方「全局变量」）
- `#Cval let`：编译期常量（局部 / 全局，见下文）
- `#Frozen let`：深不可变（含字段时禁子字段写，详见所有权章）
- 注解 `#Mut` / `#Cval` / `#Frozen` 三者**互斥**

## 局部编译期常量 `#Cval let`

`#Cval let` 在函数 / 块作用域内声明编译期常量，初值必须是**编译期可求值**的常量表达式：

```yux
fn area_of_unit_square() i32 {
  #Cval let SIDE i32 = 1
  #Cval let AREA i32 = SIDE * SIDE      ; 引用已声明 #Cval
  #Cval let FLAG bool = SIDE > 0 && AREA != 0
  ret AREA
}
```

允许：
- 字面量（数值 / `bool` / `null` / 字符串 / `codePoint`）
- 已声明 `#Cval` 名字引用
- 算术 / 位 / 比较 / 逻辑 / 括号组合
- `#Const fn` 调用（callee 标 `#Const`，实参全 const）
- struct 字面量 `<Type> { .f = const-expr ... }`（全字段公开、全初值 const）

不允许：非 `#Const` fn 调用、堆构造（`Rc` / `Array` / `String`）、`T&` 引用、`if`/`match` 控制流等。违反者报 `E3104` / `E3140`。

## 全局变量

全局变量在顶层声明，按注解分三档：

| 档位 | 写法 | 语义 |
|---|---|---|
| 全局 val | `let NAME T = expr` | 运行期初始化，浅不可变 |
| 全局 `#Mut` | `#Mut` 顶行 + `let NAME T = expr` | 运行期初始化，可变 |
| 全局 `#Cval` | `#Cval` 顶行 + `let NAME T = expr` | 编译期求值，不可变 |
| 全局 `#Inline` `#Cval` | `#Inline` + `#Cval` 顶行 + `let NAME T = expr` | 内联常量：无 LLVM 符号，使用处直接替换值（类似 C `#define`） |

全局 val 与 `#Mut` 的初始化器在运行期执行（可调任意 fn、可含 struct 字面量），编译器按模块拓扑序在主函数前自动调用 `_yux_global_init`。`#Cval` 的初始化器在编译期求值，直接写入只读数据段。

v1 所有全局变量**必须**带初值（`#Mut` 延后赋值留待后续）。

```yux
; 全局 val（运行期 init，不可变）
let DEFAULT_PORT i32 = 8080
let CONFIG Config = load_config()

; 全局 #Mut（运行期 init，可变）
#Mut
let counter i64 = 0
#Mut
let cache Array<String> = Array:<String>()

; 全局 #Cval（编译期求值，不可变）
#Cval
let MAX_SIZE i32 = 1024
#Cval
let PI f64 = 3.14159

; 算术表达式
#Cval
let DOUBLE i32 = MAX_SIZE * 2

; #Const fn 调用
#Cval
let OFFSET i32 = compute_offset(MAX_SIZE, 10)

; struct 字面量（多行块）
#Cval
let ORIGIN Point = Point {
  .x = 0
  .y = 0
}

; 私有全局（_开头）
let _INTERNAL_ID i64 = generate_id()

fn main() {
  println(MAX_SIZE)
  println(ORIGIN.x)
  Counter::inc()
}
```

> 全局 `#Cval let` 的初值在 **sema 期** 完成全部求值，codegen 直接翻为 LLVM Constant 写入 rodata，不产生运行时代码。全局 val / `#Mut` 的 init 走 `_yux_global_init` 在 main 之前执行；const-evaluable 的 init 自动优先走常量通路（无运行期开销）。

## 表达式

### 算术运算

```yux
let a = 10 + 5
let b = 10 - 5
let c = 10 * 5
let d = 10 / 5
let e = 10 % 3
```

### 复合赋值运算

```yux
#Mut let a i32 = 10
a += 5
a -= 3
a *= 2
a /= 4
a %= 4

; 位运算
#Mut let b i32 = 16
b >>= 2
b <<= 1
b ^= 0xFF
b |= 0x0F
b &= 0xF0
```

### 移入赋值 `<-`

`a <- b` 把 `a` 的旧值**移出**（返回旧值），同时把 `b` 的值**写入** `a`。与 `a = b` 不同：`=` 不产生值（仅修改），`<-` 是表达式，返回移出的旧值。

```yux
; 标量 swap
#Mut let a i32 = 10
#Mut let b i32 = 20
let old = a <- b        ; old = 10, a = 20, b 不变

; 堆句柄交换（无 double-free）
#Mut let x Rc<Point> = Point::make(1, 2)
#Mut let y Rc<Point> = Point::make(3, 4)
let prev = x <- y       ; prev 持有原 x 的 Rc, x 现在指向 y 的 Rc

; 字段级移入
let old_field = s.f <- Data::make(42)
```

> **注意**：`<-` 是**表达式**，优先级最低，右结合。左侧必须是可写的位置（变量、字段、元组成员）。

### 比较与逻辑运算

```yux
let a = 10 == 5
let b = 10 != 5
let c = 10 > 5
let d = 10 >= 5
let e = 10 < 5
let f = 10 <= 5

; 逻辑运算
let g = true && false
let h = true || false
```

### 位运算

```yux
let a = 0xF0 & 0x0F  ; 按位与
let b = 0xF0 | 0x0F  ; 按位或
let c = 0xFF ^ 0x0F  ; 按位异或
let d = 1 << 4       ; 左移
let e = 16 >> 2      ; 右移
```

### 一元运算

```yux
let a = -10
let b = -3.14
let c = ~5      ; 按位取反
let d = !true   ; 逻辑取反
```

### 运算符优先级（从低到高）

1. 比较/逻辑运算符：`==`, `!=`, `>`, `>=`, `<`, `<=`, `&&`, `||`
2. 加减运算符：`+`, `-`
3. 乘除模运算符：`*`, `/`, `%`
4. 移位运算符：`<<`, `>>`
5. 位运算符：`&`, `|`, `^`
6. 一元运算符：`!`, `~`, `-`（无空格）
7. 后缀运算符：成员访问 `.`、索引 `[]`、函数调用 `()`

## 数组访问

```yux
arr[1] = 25
```



## 单行 / 多行写法

函数声明、调用、数组字面量、下标、链式 `.` / `?.` 都支持单行 + 多行两种写法：

```yux
; 多行调用（末参允许尾随 `,`）
let u = make_user(
  "alice",
  30,
  "a@x.io",
)

; 多行数组
let xs = [
  1,
  2,
  3,
]

; 链式调用
let s = builder
  .with_a(1)
  .with_b(2)
  .build()
```

> 列宽阈值默认 120；格式化器在两种形态间自动选择，手写的链式换行会被保留。
