# 基础语法

本文档介绍 yux 语言的基础语法规则。

## 注释

```yux
; 顶行注释，缩进也可
fn some() {
  ; 也可缩进
  println(123) ; 尾随注释
}
```

**说明：**
- 顶行注释：`;` 位于行首（可以有缩进）
- 尾随注释：空格 `;` 开头（代码行或空行后）

## 空格规则

- 关键字后必须有空格
- 二元运算符两边必须有空格
- `()` `[]` 内部无空格
- `,` 后有空格

```yux
; 正确
fn add(a i32, b i32) i32 = a + b
val arr = [1, 2, 3]

; 错误
fn add(a i32,b i32)i32=a+b ; 缺少空格
val arr = [ 1,2,3 ]        ; 括号内多余空格
```

## 变量声明

```yux
; 可变变量（带初始化）
var a i32 = 10
a = 20

; 不可变变量（带初始化）
val b i64 = 100
; b = 200 ; 错误：不可重新赋值

; 类型推断
val c = 123
val d = 3.14
val e = true

; 无初始化声明
var x i32      ; 声明可变变量，稍后赋值
var y i64
x = 42         ; 后续赋值
y = 100

val z f32      ; 声明不可变变量，稍后赋值
z = 3.14       ; 后续赋值（仅允许一次）
```

**说明：**
- `var`：可变变量，可以重新赋值
- `val`：不可变变量，只能赋值一次
- `cval`：编译时常量（用于全局常量，见下文）
- 声明时可以带初始化，也可以先声明后赋值
- 无初始化声明时必须显式指定类型

## 全局常量

使用 `cval` 关键字声明全局常量，在编译时确定值：

```yux
; 公开全局常量
cval MAX_SIZE i32 = 1024
cval PI f64 = 3.14159

; 私有全局常量（_开头）
cval _INTERNAL_CONST i32 = 42

fn main() {
  println(MAX_SIZE.to_string())
  println(_INTERNAL_CONST.to_string())
}
```

## 表达式

### 算术运算

```yux
val a = 10 + 5
val b = 10 - 5
val c = 10 * 5
val d = 10 / 5
val e = 10 % 3
```

### 复合赋值运算

```yux
var a i32 = 10
a += 5
a -= 3
a *= 2
a /= 4
a %= 4

; 位运算
var b i32 = 16
b >>= 2
b <<= 1
```

### 比较与逻辑运算

```yux
val a = 10 == 5
val b = 10 != 5
val c = 10 > 5
val d = 10 >= 5
val e = 10 < 5
val f = 10 <= 5

; 逻辑运算
val g = true && false
val h = true || false
```

### 位运算

```yux
val a = 0xF0 & 0x0F  ; 按位与
val b = 0xF0 | 0x0F  ; 按位或
val c = 0xFF ^ 0x0F  ; 按位异或
val d = 1 << 4       ; 左移
val e = 16 >> 2      ; 右移
```

### 一元运算

```yux
val a = -10
val b = -3.14
val c = ~5      ; 按位取反
val d = !true   ; 逻辑取反
```

### 运算符优先级（从低到高）

1. 比较/逻辑运算符：`==`, `!=`, `>`, `>=`, `<`, `<=`, `&&`, `||`
2. 加减运算符：`+`, `-`
3. 乘除模运算符：`*`, `/`, `%`
4. 移位运算符：`<<`, `>>`
5. 位运算符：`&`, `|`, `^`
6. 一元运算符：`!`, `~`, `-`（无空格）
7. 后缀运算符：成员访问 `.`、索引 `[]`、函数调用 `()`

## 数组访问

```yux
val arr = [10, 20, 30]
val first = arr[0]
arr[1] = 25
```

## 成员访问

```yux
val n = N(1.5)
val x = n.field
```

## 函数调用

```yux
val result = add(1, 2)
println(result.to_string())
```
