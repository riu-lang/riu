# 基础语法

本文档介绍 yux 语言的基础语法规则。

## 注释

```yux
; 顶行注释，缩进也可
fn some() {
  ; 也可缩进
  println(123) ; 尾随注释
}
```

**说明：**
- 顶行注释：`;` 位于行首（可以有缩进）
- 尾随注释：空格 `;` 开头（代码行或空行后）

## 空格规则

- 关键字后必须有空格
- 二元运算符两边必须有空格
- `()` `[]` 内部无空格
- `,` 后有空格

```yux
; 正确
fn add(a i32, b i32) i32 = a + b
val arr = [1, 2, 3]

; 错误
fn add(a i32,b i32)i32=a+b ; 缺少空格
val arr = [ 1,2,3 ]        ; 括号内多余空格
```

## 变量声明

```yux
; 可变变量
var a i32 = 10
a = 20

; 不可变变量
val b i64 = 100
; b = 200 ; 错误：不可重新赋值

; 类型推断
val c = 123
val d = 3.14
val e = true
```

## 全局常量

使用 `cval` 关键字声明全局常量，在编译时确定值：

```yux
; 公开全局常量
cval MAX_SIZE i32 = 1024
cval PI f64 = 3.14159

; 私有全局常量（_开头）
cval _INTERNAL_CONST i32 = 42

fn main() {
  println(MAX_SIZE.to_string())
  println(_INTERNAL_CONST.to_string())
}
```

## 表达式

### 算术运算

```yux
val a = 10 + 5
val b = 10 - 5
val c = 10 * 5
val d = 10 / 5
val e = 10 % 3
```

### 复合赋值运算

```yux
var a i32 = 10
a += 5
a -= 3
a *= 2
a /= 4
a %= 4

; 位运算
var b i32 = 16
b >>= 2
b <<= 1
```

### 比较运算

```yux
val a = 10 == 5
val b = 10 != 5
val c = 10 > 5
val d = 10 >= 5
val e = 10 < 5
val f = 10 <= 5
```

### 一元运算

```yux
val a = -10
val b = -3.14
val c = ~5
val d = !true
```

### 运算符优先级（从低到高）

1. 比较运算符：`==`, `!=`, `>`, `>=`, `<`, `<=`
2. 加减运算符：`+`, `-`
3. 乘除模运算符：`*`, `/`, `%`
4. 一元运算符：`!`, `~`, `-`（无空格）
5. 后缀运算符：函数调用 `.`, `[]`, `()`

## 数组访问

```yux
val arr = [10, 20, 30]
val first = arr[0]
arr[1] = 25
```

## 成员访问

```yux
val n = N(1.5)
val x = n.field
```

## 函数调用

```yux
val result = add(1, 2)
println(result.to_string())
```
