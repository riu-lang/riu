# yux 内置类型

本文档详细介绍 yux 语言的内置类型系统，包括基本类型、内置泛型类型和类型转换。

## 基本类型

### 整数类型

yux 提供多种位宽的有符号和无符号整数类型：

| 类型 | 说明 | 范围 | LLVM 类型 |
|------|------|------|-----------|
| `i8` | 8位有符号整数 | -128 ~ 127 | i8 |
| `u8` | 8位无符号整数 | 0 ~ 255 | i8 |
| `i16` | 16位有符号整数 | -32768 ~ 32767 | i16 |
| `u16` | 16位无符号整数 | 0 ~ 65535 | i16 |
| `i32` | 32位有符号整数 | -2147483648 ~ 2147483647 | i32 |
| `u32` | 32位无符号整数 | 0 ~ 4294967295 | i32 |
| `i64` | 64位有符号整数 | -9223372036854775808 ~ 9223372036854775807 | i64 |
| `u64` | 64位无符号整数 | 0 ~ 18446744073709551615 | i64 |

#### 整数字面量

```yux
; 十进制
val a = 42
val b = -123

; 二进制（0b 前缀）
val c = 0b1010

; 八进制（0o 前缀）
val d = 0o755

; 十六进制（0x 前缀）
val e = 0xFF

; 带类型后缀
val f = 42i8
val g = 100u64
val h = -123i32
```

**类型后缀列表：**
- 有符号：`i8`, `i16`, `i32`, `i64`
- 无符号：`u8`, `u16`, `u32`, `u64`

#### 类型推断

无后缀整数字面量默认类型为 `i32`，但会根据上下文自动推断：

```yux
; 二元运算中匹配另一侧类型
val a u8 = 1u8 + 2       ; 2 推断为 u8
val b i64 = 100 + 200    ; 100 和 200 推断为 i64

; 声明时匹配变量类型
var x u8 = 42            ; 42 推断为 u8
x = 10                   ; 10 推断为 u8

; 返回值匹配函数返回类型
fn big() i64 {
  ret 123456789          ; 推断为 i64
}
```

### 浮点类型

| 类型 | 说明 | 精度 | LLVM 类型 |
|------|------|------|-----------|
| `f32` | 32位浮点数 | 单精度（约7位有效数字） | float |
| `f64` | 64位浮点数 | 双精度（约15位有效数字） | double |

#### 浮点字面量

```yux
val a = 3.14           ; 默认 f64
val b = 2.5f32         ; 32位浮点
val c = 1.0f64         ; 64位浮点
val d = -0.5           ; 负数
val e = 1e10           ; 科学计数法
```

### 布尔类型

```yux
val a = true
val b = false

; 布尔运算
val c = !true          ; false
val d = a && b         ; 逻辑与
val e = a || b         ; 逻辑或
```

## 内置泛型类型

### Ref<T> - 引用类型

`Ref<T>` 是不可空引用类型，编译为原始指针。

```yux
struct Point {
  x f64
  y f64
}

Point {
  fn move_to(dx f64, dy f64) {
    $.x = $.x + dx
    $.y = $.y + dy
  }
}

fn main() {
  var p = Point(1.0, 2.0)
  val ref = &p           ; 取引用
  ref.move_to(1.0, 1.0)
  println(p.x)  ; 输出 2.0
}
```

**特性：**
- 不可空引用，编译为原始指针
- 使用 `&变量` 或 `&变量.字段` 获取引用
- 函数参数为 `Ref<T>` 时，可传入 `T` 类型的值，自动取引用
- `Ref<T>` 不支持函数类型

### Box<T> - 堆对象类型

`Box<T>` 是堆分配的智能指针，使用引用计数自动管理内存。

```yux
struct Point {
  x f64
  y f64
}

Point {
  fn Point(x f64, y f64) {
    $.x = x
    $.y = y
  }
}

fn main() {
  var p Box<Point> = Point(1.0, 2.0)
  println(p.x)  ; 输出 1.0
  
  var p2 Box<Point> = p     ; 复制，引用计数 +1
  println(p2.y) ; 输出 2.0
}  ; p 和 p2 离开作用域，引用计数归零，自动释放
```

**特性：**
- 不可空的堆对象指针
- 使用引用计数自动管理内存（类似 `shared_ptr`）
- 复制 `Box<T>` 会增加引用计数
- 离开作用域时自动减少引用计数，归零时释放内存
- 成员访问与普通对象一致（自动解引用）
- 使用 Windows API (`HeapAlloc`/`HeapFree`) 管理内存

**内存布局：**

```
Box<T> 结构:
┌─────────────┬─────────────┐
│ data_ptr    │ refcount_ptr│
│ (指向T数据)  │ (指向引用计数)│
└─────────────┴─────────────┘

堆内存布局:
┌────────────┬─────────────────┐
│ refcount   │ T data          │
│ (i64)      │                 │
└────────────┴─────────────────┘
```

### Ptr<T> - 原始指针类型

`Ptr<T>` 是可空的原始指针类型。

```yux
; 声明可空指针
var p Ptr<i32> = null

; 从 Box<T> 或 Ref<T> 转换
struct Data {
  value i32
}

fn main() {
  var data Data = Data(42)
  val ref = &data
  var ptr Ptr<Data> = ref    ; Ref<T> -> Ptr<T>

  var box Box<Data> = Data(100)
  var ptr2 Ptr<Data> = box   ; Box<T> -> Ptr<T>
}
```

**特性：**
- 可空的原始指针，用 `null` 表示空指针
- 可以从 `Ref<T>` 或 `Box<T>` 直接转换
- 没有成员函数，不进行析构
- 编译为 LLVM 原始指针

### Array<T> - 动态数组类型

`Array<T>` 是堆分配的动态数组，支持运行时确定长度。

```yux
fn main() {
  ; 创建空数组
  var empty Array<i32> = []
  
  ; 创建带初始值的数组
  var arr Array<i32> = [1, 2, 3]
  
  ; 索引访问
  println(arr[0])  ; 输出 1
  
  ; 索引赋值
  arr[0] = 10
  println(arr[0])  ; 输出 10
  
  ; 不同元素类型
  var arr_f64 Array<f64> = [1.5, 2.5, 3.5]
  println(arr_f64[1])
}
```

**方法：**

| 方法 | 说明 |
|------|------|
| `len()` | 返回数组长度（i64） |
| `cap()` | 返回数组容量（i64） |
| `push(value T)` | 追加元素 |
| `clear()` | 清空数组 |
| `set_len(len i64)` | 设置长度（用于截断） |
| `is_empty()` | 判断数组是否为空（返回 bool） |
| `at(i i64)` | 获取指定位置的元素（返回 T） |
| `first()` | 获取第一个元素（返回 T） |
| `last()` | 获取最后一个元素（返回 T） |
| `pop()` | 移除并返回最后一个元素（返回 T） |

**特性：**
- 堆分配的动态数组
- 使用 Windows API (`HeapAlloc`/`HeapFree`) 管理内存
- 离开作用域时自动释放内存
- 支持空数组初始化 `[]`
- 索引访问和赋值语法与固定数组相同

**内存布局：**

```
Array<T> 结构:
┌─────────────┬─────────────┬─────────────┐
│ data_ptr    │ len         │ cap         │
│ (指向T数据)  │ (当前长度)   │ (容量)      │
└─────────────┴─────────────┴─────────────┘
```

### String - 字符串类型（不可变）

`String` 是内置的不可变字符串类型，内部使用 `Array<u32>` 存储 Unicode 码点。
所有"修改"语义一律返回新 `String`；mutable 用例走 `Array<u32>` 缓冲 + `String(buf)` 构造接管句柄。

```yux
fn main() {
  ; 字面量（落 .rodata，零分配）
  val msg = "Hello"
  println(msg)

  ; 通过 Array<u32> 缓冲构造
  var buf Array<u32> = []
  buf.push(c'H')
  buf.push(c'i')
  val s String = String(buf)
  println(s.len())

  ; 转换为 UTF-8 字节
  val bytes = s.to_bytes()
}
```

**内置方法：**

| 方法 | 说明 |
|------|------|
| `String()` | 构造空字符串 |
| `String(s String)` | 拷贝构造（句柄共享） |
| `String(buf Array<u32>)` | 接管 Array<u32> 缓冲构造（句柄共享） |
| `len()` | 返回字符数（i64） |
| `at(i i64)` | 获取指定位置的码点（u32） |
| `to_bytes()` | 转换为 UTF-8 字节数组 |

> mutator（`clear` / `append` / `sub_string`）已移除。短生命周期累积请用 `StringBuilder`，需自定义码点缓冲也可直接 `Array<u32>` + `String(buf)` 构造。
> `to_upper` / `trim` / `substring` / `repeat` 等"返回新 String"方法 v1 暂未提供。

#### 字符串模板（v0.6）

字符串字面量内可直接插值，无需前缀。两种形态：

```yux
val name String = "world"
val n i32 = 42

val a String = "hello, $name"       ; 标识符插值：$ 紧跟 ID
val b String = "n = ${n + 1}"       ; 表达式插值：${...} 包裹任意表达式
val c String = "literal \$ sign"    ; \$ 转义出字面 $（不进入插值）
```

被插值的表达式类型须为 `String` 或实现 `ToString` draft；非 `String` 由编译器自动合成 `expr.to_string()` 调用。整个模板 lower 为单条 `StringBuilder` 累加链，无中间临时 `String`。

#### 字符串 `+` 连接（v0.6）

`+` 任一操作数为 `String` 时整条左结合 `+` 链合并成一次 `StringBuilder` 累加：

```yux
val s String = "x = " + n + ", y = " + (n * 2)  ; 合法：i32 走 to_string()
```

规则与模板插值一致 —— 叶子允许 `String` 或实现 `ToString` 的类型，否则报 [E3026]。`-` / `+=` 在 `String` 上仍未定义；`String` 仍不可变，结果为新 `String`。

### StringBuilder - 可变字符串缓冲

`StringBuilder` 是可变的码点累积器，用于构造 `String`。内部持有 `Array<u32>` 缓冲；`build()` 一次性产出不可变 `String` 并重置自身——产出后继续 `append` 不会影响已返回的 `String`。

```yux
fn main() {
  var sb StringBuilder = StringBuilder()
  sb.append(c'H')
  sb.append("ello")
  sb.append(33u8)            ; '!'
  val s String = sb.build()  ; "Hello!"
  println(s)
}
```

**内置方法：**

| 方法 | 说明 |
|------|------|
| `StringBuilder()` | 构造空缓冲 |
| `len()` | 当前码点数（i64） |
| `append(cp u32)` | 追加 Unicode 码点 |
| `append(b u8)` | 追加 ASCII 字节 |
| `append(s String)` | 追加字符串全部码点 |
| `clear()` | 重置为空 |
| `build()` | 取出缓冲构造 `String`，自身重置为空 |

## 固定大小数组

固定大小数组在栈上分配，大小必须在编译时确定。

```yux
; 声明固定数组
val arr [i32 * 5] = [1, 2, 3, 4, 5]
val bytes [u8 * 4] = [97u8, 98u8, 99u8, 100u8]

; 数组填充
var buf [u8 * 21] = [0u8 ...]        ; 全部初始化为 0
var flags [bool * 5] = [true ...]    ; 全部初始化为 true

; 显式指定元素类型
var arr2 [i32 * 10] = [0 ... i32]
```

**数组填充规则：**
1. 必须指定数组类型和长度
2. 字面量类型必须与目标元素类型一致
3. `[值 ...]` 语法用指定值填充整个数组

## 类型转换

yux **不存在隐式类型转换**，所有类型转换必须显式进行。

### 数值类型转换

使用 `.to_类型()` 方法进行转换：

```yux
val a i32 = 10
val b f64 = a.to_f64()     ; i32 -> f64
val c i64 = a.to_i64()     ; i32 -> i64
val d u8 = 100u8
val e i32 = d.to_i32()     ; u8 -> i32
```

**支持的转换方法：**
- 整数：`to_i8()`, `to_u8()`, `to_i16()`, `to_u16()`, `to_i32()`, `to_u32()`, `to_i64()`, `to_u64()`
- 浮点：`to_f32()`, `to_f64()`
- 布尔：`to_bool()`（0 为 false，非零为 true）
- 字符串：`to_string()`

### 布尔转换

```yux
val a i32 = 0
val b bool = a.to_bool()   ; false（0 为 false，非零为 true）

val c i32 = 42
val d bool = c.to_bool()   ; true
```

### 字符串转换

`to_string()` 是 `ToString` draft 的契约方法，所有内置数值类型 / `bool` / `String` 都已实现。

```yux
val a i32 = 42
val s String = a.to_string()

val b f64 = 3.14
val s2 String = b.to_string()

val c bool = true
val s3 String = c.to_string()  ; "true" 或 "false"
```

> `print` / `println` 签名为 `fn<T : ToString>(x T)`，调用时无需显式 `.to_string()`：直接 `println(a)` / `println(b)` / `println(c)` 即可。字符串模板 `"x = $a"` 的插值位置也自动合成 `to_string()` 调用（详见 §字符串与模板）。

### 引用类型转换

```yux
struct Data {
  value i32
}

fn main() {
  var data Data = Data(42)
  
  ; Ref<T> -> Ptr<T>
  val ref = &data
  var ptr Ptr<Data> = ref
  
  ; Box<T> -> Ptr<T>
  var box Box<Data> = Data(100)
  var ptr2 Ptr<Data> = box
}
```

## 类型推断规则

### 变量声明

```yux
val a = 123        ; 推断为 i32
val b = 3.14       ; 推断为 f64
val c = true       ; 推断为 bool
val d = "hello"    ; 推断为 String
val e = [1, 2, 3]  ; 推断为 Array<i32>（元素推断为 i32）
```

### 二元运算

```yux
val a u8 = 1u8 + 2       ; 2 推断为 u8
val b i64 = 100 + 200    ; 100 和 200 推断为 i64
val c u32 = 5u32 * 3 + 1 ; 3 和 1 推断为 u32
```

### 函数调用

```yux
fn f(a i32, b u8) { }
val r = f(1, 2)          ; 2 自动推断为 u8（唯一匹配）

; 不能唯一确定时报错
fn g(a u8, b u8) { }
fn g(a i64, b u8) { }
; g(1, 2)  ; 错误：多个重载均可匹配
g(1u8, 2u8)              ; 显式后缀消歧
```

### 泛型函数

```yux
fn identity<T>(x T) T = x

; 显式指定类型参数
val a i32 = identity<i32>(42)

; 类型推断
val b i32 = identity(999)  ; T 推断为 i32

; 显式类型参数影响字面量推断
val c i64 = identity<i64>(100)  ; 100 推断为 i64
```

## 可见性规则

- 以 `_` 开头的标识符为私有，仅在当前模块可见
- 适用于函数、结构体、全局常量等

```yux
; 私有函数
fn _helper() {
}

; 私有全局常量
cval _INTERNAL_CONST i32 = 42

; 公开全局常量
cval MAX_SIZE i32 = 1024
```

## 空值

`null` 关键字用于表示空指针，仅适用于 `Ptr<T>` 类型：

```yux
var p Ptr<i32> = null

if p == null {
  println("pointer is null")
}
```

**注意：** `Ref<T>` 和 `Box<T>` 是不可空类型，不能赋值为 `null`。
