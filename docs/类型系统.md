# 类型系统

本文档详细介绍 yux 语言的类型系统。

## 基本类型

### 整数类型

| 类型 | 说明 | 范围 | LLVM 类型 |
|------|------|------|-----------|
| `i8` | 8位有符号整数 | -128 ~ 127 | i8 |
| `u8` | 8位无符号整数 | 0 ~ 255 | i8 |
| `i16` | 16位有符号整数 | -32768 ~ 32767 | i16 |
| `u16` | 16位无符号整数 | 0 ~ 65535 | u16 |
| `i32` | 32位有符号整数 | -2147483648 ~ 2147483647 | i32 |
| `u32` | 32位无符号整数 | 0 ~ 4294967295 | u32 |
| `i64` | 64位有符号整数 | -9223372036854775808 ~ 9223372036854775807 | i64 |
| `u64` | 64位无符号整数 | 0 ~ 18446744073709551615 | u64 |

### 浮点类型

| 类型 | 说明 | 精度 | LLVM 类型 |
|------|------|------|-----------|
| `f32` | 32位浮点数 | 单精度（约7位有效数字） | float |
| `f64` | 64位浮点数 | 双精度（约15位有效数字） | double |

### 布尔类型

| 类型 | 说明 |
|------|------|
| `bool` | 布尔值，true 或 false |

## 整数字面量

```yux
let a = 42     ; 十进制
let b = 0b1010 ; 二进制
let c = 0o755  ; 八进制
let d = 0xFF   ; 十六进制

; 带类型后缀
let e = 42i8
let f = 100u64
let g = -123i32
```

## 浮点字面量

```yux
let a = 3.14
let b = 2.5f32
let c = 1.0f64
let d = -0.5
```

## 布尔字面量

```yux
let a = true
let b = false
```

## 字符串字面量

```yux
; 双引号字符串，支持转义
let s1 = "hello world"
let s2 = "line1\nline2"
let s3 = "tab\there"
let s4 = "quote: \"text\""

; 原始字符串（r前缀），不处理转义
let path = r"C:\path\to\file"
let regex = r"\d+\.\d+"
```

**转义字符：**
- `\n` - 换行
- `\t` - 制表符
- `\\` - 反斜杠
- `\"` - 双引号
- `\'` - 单引号

## 代码点字面量

使用 `c'X'` 语法表示单个 Unicode 代码点，类型为 `u32`：

```yux
let a u32 = c'A'    ; 65
let b u32 = c'\n'   ; 10
let c u32 = c'中'   ; 20013
```

## 数组类型

### 固定大小数组

```yux
let arr [i32 * 5] = [1, 2, 3, 4, 5]
let bytes [u8 * 4] = [97u8, 98u8, 99u8, 100u8]
```

### 数组填充

```yux
#Mut let buf [u8 * 21] = [0u8 ...]
#Mut let flags [bool * 5] = [true ...]
#Mut let arr [i32 * 10] = [0 ... i32]
```

## 泛型类型

### T& - 引用类型

`T&` 是借用（不可空引用），编译为原始指针：

```yux
let ref Point& = &point
```

### Rc<T> - 堆对象类型

`Rc<T>` 是内置的堆分配智能指针，自动管理内存：

```yux
let box Rc<Point> = Rc:<Point>(Point::make(1.0, 2.0))
```

### Ptr - 原始指针类型

`Ptr` 是可空的原始指针类型（无泛型参数，等价 C `void*`），仅 FFI 边界使用：

```yux
#Mut let p Ptr = null
```

### Array<T> - 动态数组类型

`Array<T>` 是堆分配的动态数组：

```yux
#Mut let empty Array<i32> = []
#Mut let arr Array<i32> = [1, 2, 3]
```

### Nullable<T> - 可空类型

`Nullable<T>` 是 SDK 提供的包装结构体，用于表达"可能为空"的值。语法糖 `T?` 由编译器解糖为 `Nullable<T>`：

```yux
#Mut let nx i32? = 42i32   ; 持值
#Mut let ny i32? = null    ; 为空
```

**赋值规则：**
- `null` 字面量赋给 `T?` → 空值
- `T` 类型值赋给 `T?` → 隐式包装（仅在赋值/参数/返回值上下文）
- `Nullable<T>` 整体赋给同类型 → 结构体复制
- 显式构造需用 turbofish：`Nullable:<i32>(42i32)` / `Nullable:<i32>()`，详见 [函数.md](函数.md#泛型函数)

**方法：**
- `has() bool` —— 是否持值
- `get() T` —— 取出内层值；若为空则调用 `_exit(1)` 终止进程

**`??` 默认值运算符：**

```yux
#Mut let a i32 = nx ?? -1i32   ; 持值返回 42，否则 -1
```

**`?.` 安全字段访问：**

```yux
struct N { v i32 }
#Mut let maybeN N? = N::make(7)
#Mut let v1 i32? = maybeN?.v   ; 持值时为 7，否则为空
```

链式 `a?.b?.c` 自然展开。当前仅支持字段访问，不支持方法调用形式 `a?.foo()`。

### Dyn<D> - 运行时多态

`Dyn<D>` 是 fat pointer（`{ vtable_ptr, data_ptr }`），提供基于 spec 的运行时多态分发：

```yux
#Spec struct Shape {
  fn area() f64
}

struct Circle { r f64 }
#Impl(Shape)
struct Circle {
  fn area() f64 = 3.14 * $.r * $.r
}

fn main() {
  #Mut let c = Rc:<Circle>(Circle::make(1.0))
  let d Dyn<Shape> = Dyn:<Shape>(c)   ; 构造 fat pointer
  println(d.area())                    ; vtable 分发
}
```

**要点：**
- `Dyn<D>` 按值持有（owned），`Dyn<D&>` 按借用持有
- 构造通过 turbofish：`Dyn:<D>(value)`
- 方法调用走 vtable，零额外分配
- 仅 `#Spec struct` 声明的签名可进入 vtable（对象安全）

> 详见 [docs/spec/12-spec.md §12.9](spec/12-spec.md#129-dynd--dynd-运行时多态)。

## 元组类型 `(T1, T2, ...)`

元组是按结构等价的复合值类型，长度 ≥ 2，下标固定。LLVM 落地为匿名 `struct`，按值复制。

### 构造

```yux
let pair = (1, 2)                    ; 类型推断为 (i32, i32)
let triple (i32, f64, bool) = (1, 3.14, true)
let nested = (1, (2, 3))             ; (i32, (i32, i32))
```

### 成员访问 `a.0`

下标必须是字面整数；越界编译期报错（[E3100]）。

```yux
let p = (10, 20)
println(p.0)             ; 10
println(p.1)             ; 20

let nest = ((1, 2), 3)
println(nest.0.0)        ; 1，链式取值
println(nest.0.1)        ; 2
```

### 平铺解构 `(a, b) = e`

按位绑定到独立局部变量，不支持嵌套模式与 `_`。元素数必须与元组长度一致（[E3102]），右侧必须是元组类型（[E3101]）。

```yux
#Mut let (x, y) = (1, 2)             ; x i32 = 1, y i32 = 2
let (a, b, c) = make_triple()        ; 函数返回元组直接展开
```

### 成员赋值 `obj.0 = e`

仅当对象本身可变时合法；可链式 `t.0.1 = e`，并支持复合赋值 `+=` `*=` 等。

```yux
#Mut let t = (1, 2)
t.0 = 10
t.1 += 5

#Mut let nest = ((0, 0), 0)
nest.0.1 = 7
```

## 类型别名

顶层透明类型别名，编译期与目标类型完全等价（非 newtype，可隐式互转）。

```yux
IPair = (i32, i32)
Pair<T> = (T, T)

fn swap(p IPair) IPair {
  ret (p.1, p.0)
}

fn main() {
  let p IPair = (1, 2)
  let q Pair<i32> = swap(p)          ; IPair 与 Pair<i32> 等价
  println(q.0)
}
```

约束：

- 别名禁止成环（直接或间接），违者报 [E2016]。
- 别名名与已有 `struct` / 别名同名报 [E2017]。
- 别名不引入新类型；它只是目标类型的另一名字，不影响方法解析与重载。

## 类型转换

yux **不存在隐式类型转换**，所有类型必须显式转换。

使用 `.to_类型()` 方法进行类型转换：

```yux
let a i32 = 10
let b f64 = a.to_f64()
let c i64 = a.to_i64()
let d u8 = 100u8
let e i32 = d.to_i32()
```

**支持的转换方法：**
- 整数：`to_i8()`, `to_u8()`, `to_i16()`, `to_u16()`, `to_i32()`, `to_u32()`, `to_i64()`, `to_u64()`
- 浮点：`to_f32()`, `to_f64()`
- 布尔：`to_bool()`（0 为 false，非零为 true）
- 字符串：`to_string()`

## 类型推断

### 变量声明

```yux
let a = 123
let b = 3.14
let c = true
```

### 二元运算

```yux
let a u8 = 1u8 + 2
let b i64 = 100 + 200
```

### 函数调用

```yux
fn f(a i32, b u8) { }
let r = f(1, 2)
```

## 可见性规则

以 `_` 开头的标识符为私有，仅在当前模块可见：

```yux
fn _private_fn() { }
#Cval
let _INTERNAL i32 = 42
```
