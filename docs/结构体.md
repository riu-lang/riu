# 结构体

本文档介绍 yux 语言中结构体的定义和使用。

## 声明结构体

```yux
struct Point {
  x f64
  y f64
}

struct Person {
  name [u8 * 32]
  age i32
}
```

方法、静态工厂、析构函数都直接写在 `structDecl` body 内（字段段 → 析构 → 方法段）：

```yux
struct Point {
  x f64
  y f64

  ; 析构函数（可选，必须在其它 fn 之前）
  fn ~() {
    ; 清理资源
  }

  ; 静态工厂 —— 构造唯一通道（见下文）
  #Static
  fn make(x f64, y f64) Point {
    ret Self {
      .x = x
      .y = y
    }
  }

  ; 实例方法
  fn add(other Point&) Point {
    Point::make($.x + other.x, $.y + other.y)
  }
}
```

> 早期 `Type { ... }` 外置实现块与 `fn Point(...)` 构造函数形态已删除。构造唯一通道为 `#Static fn` 工厂 + `Self { ... }` 字段字面量。

### 字段可变性注解 `#Val` / `#Frozen`

字段头**上一行**可加注解收紧写权限：

```yux
struct Outer {
  inner Inner            ; 默认：随便改、子字段也能改
  #Val
  tag i32                ; 只能在构造期写；其它成员函数不可重赋
  #Frozen
  config Config          ; 同上，且子字段也禁写（深传染）
}
```

- `#Val`：**浅不可变**。构造期内可写，其它成员函数写 `$.tag = ...` 报 `E3109`。
- `#Frozen`：**深不可变**。构造期内可写，其它成员函数对该字段自身或任意子字段写均报 `E3109`。
- 两个注解互斥；同时标或重复标报 `E3108`。
- 字段层修饰**凌驾**外层变量声明：`let o Outer = Outer::make(...)` 下 `o.config = ...` 仍被拒。
- 析构函数 `fn ~()` 不受 const-mut 约束（析构本就要修改 `$`）。

## 构造与使用

yux **没有**构造函数关键字。创建结构体值的唯一通道：声明 `#Static fn` 工厂，体内用 `Self { ... }` 字段字面量产值，调用方写 `Type::factory(args)`。

```yux
struct Point {
  x i32
  y i32

  #Static
  fn make(x i32, y i32) Point {
    ret Self {
      .x = x
      .y = y
    }
  }

  #Static
  fn origin() Point {
    ret Self {
      .x = 0
      .y = 0
    }
  }
}

fn main() {
  let p1 Point = Point::make(3, 4)
  let p2 Point = Point::origin()
}
```

### struct 字面量 `<Type> { ... }` 在任意位置

自 const-eval 落地起，struct 字面量 LHS 从 `Self` 放宽到**任意可见类型名**，可在**任意表达式位置**出现（不再仅限于 `#Static fn` 体内）：

```yux
fn main() {
  ; 普通 fn body 内直接用类型名构造
  let p Point = Point {
    .x = 1
    .y = 2
  }

  ; 嵌套字面量
  let r Rect = Rect {
    .top_left = Point { .x = 0, .y = 10 }
    .bottom_right = Point { .x = 20, .y = 0 }
  }
}
```

> 多行块格式不变：每条 `.field = expr` 一行，字段间无逗号，必须列全字段。

## 析构函数

析构函数使用 `fn ~()` 语法定义，在 struct body 中必须位于其它 `fn` 之前：

```yux
struct Resource {
  data i32

  fn ~() {
    ; 离开作用域时自动调用
    $.data = 0
  }

  #Static
  fn make(val i32) Resource {
    ret Self {
      .data = val
    }
  }
}

fn test() {
  let r Resource = Resource::make(42)
  println(r.data)
} ; r 离开作用域，析构函数自动调用
```

**特性：**
- 析构函数无参数、无返回值
- 当结构体变量离开作用域时自动调用
- 如果未定义析构函数，非平凡结构体（含 RC 字段等）由编译器派生默认析构；平凡结构体不生成析构代码

## 当前实例 `$`

成员函数内部用 `$` 表示当前实例（相当于其它语言的 `this` / `self`），不需要在参数列表中显式声明：

```yux
struct Counter {
  value i32

  #Static
  fn make(initial i32) Counter {
    ret Self {
      .value = initial
    }
  }

  fn increment() {
    $.value = $.value + 1
  }

  fn get_value() i32 {
    ret $.value
  }
}
```

`$` 也可以单独作为表达式使用，表示整个当前实例本身（例如内置类型的成员函数里 `$ < 0`、`-$` 等）。

## 运算符重载

yux 支持通过定义特定名称的成员函数来实现运算符重载。当对自定义类型使用运算符时，编译器会自动将其转换为对应的方法调用。

### 可重载的运算符

二元运算符方法的形参类型固定为 `Self&`（接收者类型的借用，详见下方「注意事项 #2」）；
按值 `Self` 形式不会被运算符位置触发。

| 运算符 | 方法名 | 参数 | 返回值 | 说明 |
|--------|--------|------|--------|------|
| `+` | `plus` | `Self&` | 同类型 | 加法 |
| `-` | `minus` | `Self&` | 同类型 | 减法 |
| `*` | `mul` | `Self&` | 同类型 | 乘法 |
| `/` | `div` | `Self&` | 同类型 | 除法 |
| `%` | `mod` | `Self&` | 同类型 | 取模 |
| `==` | `eq` | `Self&` | `bool` | 等于 |
| `!=` | `ne` | `Self&` | `bool` | 不等于 |
| `<` | `lt` | `Self&` | `bool` | 小于 |
| `<=` | `le` | `Self&` | `bool` | 小于等于 |
| `>` | `gt` | `Self&` | `bool` | 大于 |
| `>=` | `ge` | `Self&` | `bool` | 大于等于 |
| `&` | `and` | `Self&` | 同类型 | 按位与 |
| `\|` | `or` | `Self&` | 同类型 | 按位或 |
| `^` | `xor` | `Self&` | 同类型 | 按位异或 |
| `<<` | `shl` | `Self&` | 同类型 | 左移 |
| `>>` | `shr` | `Self&` | 同类型 | 右移 |
| `-` (一元) | `neg` | 无 | 同类型 | 取负 |
| `~` | `inv` | 无 | 同类型 | 按位取反 |
| `!` | `not` | 无 | `bool` | 逻辑非 |

### 示例：实现 Point 的加法

```yux
struct Point {
  x f64
  y f64

  #Static
  fn make(x f64, y f64) Point {
    ret Self {
      .x = x
      .y = y
    }
  }

  ; 实现 + 运算符（形参必须为 Self&）
  fn plus(other Point&) Point {
    Point::make($.x + other.x, $.y + other.y)
  }
}

fn main() {
  let p1 Point = Point::make(1.0, 2.0)
  let p2 Point = Point::make(3.0, 4.0)
  let p3 Point = p1 + p2  ; 等价于 p1.plus(&p2)

  println(p3.x)  ; 输出 4
  println(p3.y)  ; 输出 6
}
```

### 示例：实现复数类型

```yux
struct Complex {
  real f64
  imag f64

  #Static
  fn make(real f64, imag f64) Complex {
    ret Self {
      .real = real
      .imag = imag
    }
  }

  ; 加法（形参用 Complex&，避免按值复制）
  fn plus(other Complex&) Complex {
    Complex::make($.real + other.real, $.imag + other.imag)
  }

  ; 减法
  fn minus(other Complex&) Complex {
    Complex::make($.real - other.real, $.imag - other.imag)
  }

  ; 乘法
  fn mul(other Complex&) Complex {
    let r f64 = $.real * other.real - $.imag * other.imag
    let i f64 = $.real * other.imag + $.imag * other.real
    Complex::make(r, i)
  }

  ; 等于比较
  fn eq(other Complex&) bool {
    $.real == other.real && $.imag == other.imag
  }

  ; 取负
  fn neg() Complex {
    Complex::make(-$.real, -$.imag)
  }
}

fn main() {
  let c1 Complex = Complex::make(1.0, 2.0)
  let c2 Complex = Complex::make(3.0, 4.0)
  let c3 Complex = c1 + c2      ; 加法
  let c4 Complex = c1 - c2      ; 减法
  let c5 Complex = c1 * c2      ; 乘法
  let c6 Complex = -c1          ; 取负
  let eq bool = c1 == c2        ; 比较
}
```

### 注意事项

1. **运算符方法必须是成员函数**：不能是独立函数
2. **参数必须是 `Self&`**：二元运算符方法的形参类型固定为 `Self&`（接收者类型的借用）；写成按值的 `Self` 不会被运算符触发，只是普通方法。这样既避免按值复制成本，也与 `$` 接收者形态一致
3. **运算符位置自动取址**：`a == b` 编译期重写为 `a.eq(&b)`，调用方无需写 `&`；这是仅在运算符位置生效的局部例外
4. **返回值类型**：算术运算符通常返回同类型，比较运算符返回 `bool`
5. **内置类型也支持**：内置类型（如 `i32`、`f64` 等）也定义了这些运算符方法，但由编译器内部实现（标记为 `#CompilerInner`）

## 静态函数 `#Static` 与 `Type::name(...)`

除实例方法外，struct body 内**还可以**写**静态函数**（关联函数）。静态函数没有接收者 `$`，挂在类型命名空间下，调用语法 `Type::name(...)`。

### 声明

注解 `#Static` 紧贴 `fn` 头；体内可以写 `Self` 类型字面量与 `Self { ... }` 字段字面量：

```yux
struct Point {
  x i32
  y i32

  #Static
  fn make(x i32, y i32) Point {
    ret Self {
      .x = x
      .y = y
    }
  }

  #Static
  fn origin() Point {
    ret Self {
      .x = 0
      .y = 0
    }
  }

  fn sum() i32 = $.x + $.y
}

fn main() {
  let p Point = Point::make(3i32, 4i32)
  let o Point = Point::origin()
}
```

要点：

1. **没有 `$`**：体内不能写 `$` / `$.field`，否则报 `E3128`；想访问接收者类型用 `Self`。
2. **`Self { ... }` 是低层构造原语**：`.field = expr` 多行写法、无逗号；字段必须列全（不写的字段不存在默认值）。
3. **`Type { ... }` 字面量可在任意位置使用**（const-eval 落地后）：LHS 从 `Self` 放宽到任意类型名，出现位置不再仅限于 `#Static fn` 体内。普通 fn body、全局 `#Cval` RHS、`#Const fn` body 等均可写 `Point { .x = 1, .y = 2 }`。
4. **`Type::name` 调用语法**：与 `enum::variant` 共用 token `::`；编译器按 LHS 类型自动分流。

### `Self` 类型字面量

`Self` 是保留字，在方法块内绑定为所属结构体类型。允许位置：fn 返回类型、形参类型、局部 `let` 类型、turbofish 实参、`Self::name(...)` 调用 LHS、`Self { ... }` 字段字面量 LHS。**字段类型位禁用** `Self`（自引用须 `Rc<Self>?` / `Weak<Self>?`）。

### SDK 示例

SDK 已落地的静态工厂：

| 类型 | 工厂 |
|---|---|
| `String` | `String::empty()` / `String::from(buf Array<u32>)` |
| `StringBuilder` | `StringBuilder::empty()` |
| `Nullable<T>` | `Nullable:<T>::some(v T)` / `Nullable:<T>::none()` |

> 早期 `fn StructName(...)` 构造函数形态已删除；构造唯一通道为 `#Static fn` 工厂 + `Self { ... }`。
