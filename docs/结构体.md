# 结构体

本文档介绍 yux 语言中结构体的定义和使用。

## 声明结构体

```yux
struct Point {
  x f64
  y f64
}

struct Person {
  name [u8 * 32]
  age i32
}
```

## 实现结构体

```yux
Point {
  ; 析构函数（必须在第一位）
  fn ~() {
    ; 清理资源
  }

  ; 构造函数（与结构体同名）
  fn Point(x f64, y f64) {
    self.x = x
    self.y = y
  }

  ; 成员函数
  fn add(other Point) Point {
    Point(self.x + other.x, self.y + other.y)
  }
}
```

## 析构函数

析构函数使用 `fn ~()` 语法定义，在结构体实现块中必须位于第一位：

```yux
struct Resource {
  data i32
}

Resource {
  fn ~() {
    ; 离开作用域时自动调用
    self.data = 0
  }

  fn Resource(val i32) {
    self.data = val
  }
}

fn test() {
  var r Resource = Resource(42)
  println(r.data.to_string())
} ; r 离开作用域，析构函数自动调用
```

**特性：**
- 析构函数无参数、无返回值
- 当结构体变量离开作用域时自动调用
- 如果未定义析构函数，则不会自动生成

## 使用结构体

```yux
val p1 = Point(1.0, 2.0)
val p2 = Point(3.0, 4.0)
val p3 = p1.add(p2)
```

## self 参数

成员函数的第一个参数是 `self`，表示当前实例：

```yux
struct Counter {
  value i32
}

Counter {
  fn Counter(initial i32) {
    self.value = initial
  }
  
  fn increment(self Ref<Counter>) {
    self.value = self.value + 1
  }
  
  fn get_value(self Ref<Counter>) i32 {
    ret self.value
  }
}
```

## 成员函数中的 Ref<T>

使用 `Ref<T>` 可以在成员函数中直接修改对象：

```yux
struct Point {
  x f64
  y f64
}

Point {
  fn Point(x f64, y f64) {
    self.x = x
    self.y = y
  }
  
  fn move_to(self Ref<Point>, dx f64, dy f64) {
    self.x = self.x + dx
    self.y = self.y + dy
  }
}
```
