# 结构体

本文档介绍 yux 语言中结构体的定义和使用。

## 声明结构体

```yux
struct Point {
  x f64
  y f64
}

struct Person {
  name [u8 * 32]
  age i32
}
```

## 实现结构体

```yux
Point {
  ; 析构函数（必须在第一位）
  fn ~() {
    ; 清理资源
  }

  ; 构造函数（与结构体同名）
  fn Point(x f64, y f64) {
    $.x = x
    $.y = y
  }

  ; 成员函数
  fn add(other Point) Point {
    Point($.x + other.x, $.y + other.y)
  }
}
```

## 析构函数

析构函数使用 `fn ~()` 语法定义，在结构体实现块中必须位于第一位：

```yux
struct Resource {
  data i32
}

Resource {
  fn ~() {
    ; 离开作用域时自动调用
    $.data = 0
  }

  fn Resource(val i32) {
    $.data = val
  }
}

fn test() {
  var r Resource = Resource(42)
  println(r.data.to_string())
} ; r 离开作用域，析构函数自动调用
```

**特性：**
- 析构函数无参数、无返回值
- 当结构体变量离开作用域时自动调用
- 如果未定义析构函数，则不会自动生成

## 使用结构体

```yux
val p1 = Point(1.0, 2.0)
val p2 = Point(3.0, 4.0)
val p3 = p1.add(p2)
```

## 当前实例 `$`

成员函数内部用 `$` 表示当前实例（相当于其它语言的 `this` / `self`），不需要在参数列表中显式声明：

```yux
struct Counter {
  value i32
}

Counter {
  fn Counter(initial i32) {
    $.value = initial
  }

  fn increment() {
    $.value = $.value + 1
  }

  fn get_value() i32 {
    ret $.value
  }
}
```

`$` 也可以单独作为表达式使用，表示整个当前实例本身（例如内置类型的成员函数里 `$ < 0`、`-$` 等）。

## 运算符重载

yux 支持通过定义特定名称的成员函数来实现运算符重载。当对自定义类型使用运算符时，编译器会自动将其转换为对应的方法调用。

### 可重载的运算符

二元运算符方法的形参类型固定为 `Self&`（接收者类型的借用，详见下方「注意事项 #2」）；
按值 `Self` 形式不会被运算符位置触发。

| 运算符 | 方法名 | 参数 | 返回值 | 说明 |
|--------|--------|------|--------|------|
| `+` | `plus` | `Self&` | 同类型 | 加法 |
| `-` | `minus` | `Self&` | 同类型 | 减法 |
| `*` | `mul` | `Self&` | 同类型 | 乘法 |
| `/` | `div` | `Self&` | 同类型 | 除法 |
| `%` | `mod` | `Self&` | 同类型 | 取模 |
| `==` | `eq` | `Self&` | `bool` | 等于 |
| `!=` | `ne` | `Self&` | `bool` | 不等于 |
| `<` | `lt` | `Self&` | `bool` | 小于 |
| `<=` | `le` | `Self&` | `bool` | 小于等于 |
| `>` | `gt` | `Self&` | `bool` | 大于 |
| `>=` | `ge` | `Self&` | `bool` | 大于等于 |
| `&` | `and` | `Self&` | 同类型 | 按位与 |
| `\|` | `or` | `Self&` | 同类型 | 按位或 |
| `^` | `xor` | `Self&` | 同类型 | 按位异或 |
| `<<` | `shl` | `Self&` | 同类型 | 左移 |
| `>>` | `shr` | `Self&` | 同类型 | 右移 |
| `-` (一元) | `neg` | 无 | 同类型 | 取负 |
| `~` | `inv` | 无 | 同类型 | 按位取反 |
| `!` | `not` | 无 | `bool` | 逻辑非 |

### 示例：实现 Point 的加法

```yux
struct Point {
  x f64
  y f64
}

Point {
  fn Point(x f64, y f64) {
    $.x = x
    $.y = y
  }

  ; 实现 + 运算符（形参必须为 Self&）
  fn plus(other Point&) Point {
    Point($.x + other.x, $.y + other.y)
  }
}

fn main() {
  val p1 = Point(1.0, 2.0)
  val p2 = Point(3.0, 4.0)
  val p3 = p1 + p2  ; 等价于 p1.plus(p2)
  
  println(p3.x.to_string())  ; 输出 4
  println(p3.y.to_string())  ; 输出 6
}
```

### 示例：实现复数类型

```yux
struct Complex {
  real f64
  imag f64
}

Complex {
  fn Complex(real f64, imag f64) {
    $.real = real
    $.imag = imag
  }

  ; 加法（形参用 Complex&，避免按值复制）
  fn plus(other Complex&) Complex {
    Complex($.real + other.real, $.imag + other.imag)
  }

  ; 减法
  fn minus(other Complex&) Complex {
    Complex($.real - other.real, $.imag - other.imag)
  }

  ; 乘法
  fn mul(other Complex&) Complex {
    val r = $.real * other.real - $.imag * other.imag
    val i = $.real * other.imag + $.imag * other.real
    Complex(r, i)
  }

  ; 等于比较
  fn eq(other Complex&) bool {
    $.real == other.real && $.imag == other.imag
  }

  ; 取负
  fn neg() Complex {
    Complex(-$.real, -$.imag)
  }
}

fn main() {
  val c1 = Complex(1.0, 2.0)
  val c2 = Complex(3.0, 4.0)
  val c3 = c1 + c2      ; 加法
  val c4 = c1 - c2      ; 减法
  val c5 = c1 * c2      ; 乘法
  val c6 = -c1          ; 取负
  val eq = c1 == c2     ; 比较
}
```

### 注意事项

1. **运算符方法必须是成员函数**：不能是独立函数
2. **参数必须是 `Self&`**：二元运算符方法的形参类型固定为 `Self&`（接收者类型的借用）；写成按值的 `Self` 不会被运算符触发，只是普通方法。这样既避免按值复制成本，也与 `$` 接收者形态一致
3. **运算符位置自动取址**：`a == b` 编译期重写为 `a.eq(&b)`，调用方无需写 `&`；这是仅在运算符位置生效的局部例外
4. **返回值类型**：算术运算符通常返回同类型，比较运算符返回 `bool`
5. **内置类型也支持**：内置类型（如 `i32`、`f64` 等）也定义了这些运算符方法，但由编译器内部实现（标记为 `#CompilerInner`）
