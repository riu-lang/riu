# 结构体

本文档介绍 yux 语言中结构体的定义和使用。

## 声明结构体

```yux
struct Point {
  x f64
  y f64
}

struct Person {
  name [u8 * 32]
  age i32
}
```

### 字段可变性注解 `#Val` / `#Frozen`

字段头**上一行**可加注解收紧写权限：

```yux
struct Outer {
  inner Inner            ; 默认：随便改、子字段也能改
  #Val
  tag i32                ; 只能在构造函数里写；其它成员函数不可重赋
  #Frozen
  config Config          ; 同上，且子字段也禁写（深传染）
}
```

- `#Val`：**浅不可变**。构造期内可写，其它成员函数写 `$.tag = ...` 报 `E3109`，但 `$.tag` 自身有子字段时仍可改子字段。
- `#Frozen`：**深不可变**。构造期内可写，其它成员函数对该字段自身或任意子字段写均报 `E3109`。
- 两个注解互斥；同时标或重复标报 `E3108`。
- 字段层修饰**凌驾**外层变量声明：`#Mut let o Outer = Outer::make(...)` 下 `o.config = ...` 仍被拒。
- 析构函数 `fn ~()` 不受 const-mut 约束（析构本就要修改 `$`）。

## 实现结构体

```yux
Point {
  ; 析构函数（必须在第一位）
  fn ~() {
    ; 清理资源
  }

  ; 静态工厂（替代旧构造函数）
  #Static
  fn make(x f64, y f64) Point {
    ret Self {
      .x = x
      .y = y
    }
  }

  ; 成员函数
  fn add(other Point) Point {
    Point::make($.x + other.x, $.y + other.y)
  }
}
```

## 析构函数

析构函数使用 `fn ~()` 语法定义，在结构体实现块中必须位于第一位：

```yux
struct Resource {
  data i32
}

Resource {
  fn ~() {
    ; 离开作用域时自动调用
    $.data = 0
  }

  #Static
  fn make(value i32) Resource {
    ret Self { .data = value }
  }
}

fn test() {
  #Mut let r = Resource::make(42)
  println(r.data)
} ; r 离开作用域，析构函数自动调用
```

**特性：**
- 析构函数无参数、无返回值
- 当结构体变量离开作用域时自动调用
- 如果未定义析构函数，则不会自动生成

## 使用结构体

构造结构体值有两种方式：走工厂函数 `Type::make(...)` 或直接用 struct 字面量 `<Type> { ... }`：

```yux
; 方式一：通过静态工厂
let p1 = Point::make(1.0, 2.0)
let p2 = Point::make(3.0, 4.0)

; 方式二：struct 字面量（任意 expr 位置均可）
let p3 = Point {
  .x = 5.0
  .y = 6.0
}

let p4 = p1.add(p2)
```

struct 字面量 `<Type> { .field = expr ... }` 可在任意表达式位置出现：普通 fn body、全局 `#Cval` RHS、`#Const fn` body、嵌套字面量字段值等。多行块格式不变（多行 + 无逗号 + 全字段）。LHS 在 struct body 内可写 `Self`，在任意位置写具体类型名（如 `Point { ... }`）。

## 当前实例 `$`

成员函数内部用 `$` 表示当前实例（相当于其它语言的 `this` / `self`），不需要在参数列表中显式声明：

```yux
struct Counter {
  value i32
}

Counter {
  #Static
  fn make(initial i32) Counter {
    ret Self { .value = initial }
  }

  fn increment() {
    $.value = $.value + 1
  }

  fn get_value() i32 {
    ret $.value
  }
}
```

`$` 也可以单独作为表达式使用，表示整个当前实例本身（例如内置类型的成员函数里 `$ < 0`、`-$` 等）。

## 运算符重载

yux 支持通过定义特定名称的成员函数来实现运算符重载。当对自定义类型使用运算符时，编译器会自动将其转换为对应的方法调用。

### 可重载的运算符

二元运算符方法的形参类型固定为 `Self&`（接收者类型的借用，详见下方「注意事项 #2」）；
按值 `Self` 形式不会被运算符位置触发。

| 运算符 | 方法名 | 参数 | 返回值 | 说明 |
|--------|--------|------|--------|------|
| `+` | `plus` | `Self&` | 同类型 | 加法 |
| `-` | `minus` | `Self&` | 同类型 | 减法 |
| `*` | `mul` | `Self&` | 同类型 | 乘法 |
| `/` | `div` | `Self&` | 同类型 | 除法 |
| `%` | `mod` | `Self&` | 同类型 | 取模 |
| `==` | `eq` | `Self&` | `bool` | 等于 |
| `!=` | `ne` | `Self&` | `bool` | 不等于 |
| `<` | `lt` | `Self&` | `bool` | 小于 |
| `<=` | `le` | `Self&` | `bool` | 小于等于 |
| `>` | `gt` | `Self&` | `bool` | 大于 |
| `>=` | `ge` | `Self&` | `bool` | 大于等于 |
| `&` | `and` | `Self&` | 同类型 | 按位与 |
| `\|` | `or` | `Self&` | 同类型 | 按位或 |
| `^` | `xor` | `Self&` | 同类型 | 按位异或 |
| `<<` | `shl` | `Self&` | 同类型 | 左移 |
| `>>` | `shr` | `Self&` | 同类型 | 右移 |
| `-` (一元) | `neg` | 无 | 同类型 | 取负 |
| `~` | `inv` | 无 | 同类型 | 按位取反 |
| `!` | `not` | 无 | `bool` | 逻辑非 |

### 示例：实现 Point 的加法

```yux
struct Point {
  x f64
  y f64
}

Point {
  #Static
  fn make(x f64, y f64) Point {
    ret Self {
      .x = x
      .y = y
    }
  }

  ; 实现 + 运算符（形参必须为 Self&）
  fn plus(other Point&) Point {
    Point::make($.x + other.x, $.y + other.y)
  }
}

fn main() {
  let p1 = Point::make(1.0, 2.0)
  let p2 = Point::make(3.0, 4.0)
  let p3 = p1 + p2  ; 等价于 p1.plus(p2)

  println(p3.x)  ; 输出 4
  println(p3.y)  ; 输出 6
}
```

### 示例：实现复数类型

```yux
struct Complex {
  real f64
  imag f64
}

Complex {
  #Static
  fn make(real f64, imag f64) Complex {
    ret Self {
      .real = real
      .imag = imag
    }
  }

  ; 加法（形参用 Complex&，避免按值复制）
  fn plus(other Complex&) Complex {
    Complex::make($.real + other.real, $.imag + other.imag)
  }

  ; 减法
  fn minus(other Complex&) Complex {
    Complex::make($.real - other.real, $.imag - other.imag)
  }

  ; 乘法
  fn mul(other Complex&) Complex {
    let r = $.real * other.real - $.imag * other.imag
    let i = $.real * other.imag + $.imag * other.real
    Complex::make(r, i)
  }

  ; 等于比较
  fn eq(other Complex&) bool {
    $.real == other.real && $.imag == other.imag
  }

  ; 取负
  fn neg() Complex {
    Complex::make(-$.real, -$.imag)
  }
}

fn main() {
  let c1 = Complex::make(1.0, 2.0)
  let c2 = Complex::make(3.0, 4.0)
  let c3 = c1 + c2      ; 加法
  let c4 = c1 - c2      ; 减法
  let c5 = c1 * c2      ; 乘法
  let c6 = -c1          ; 取负
  let eq = c1 == c2     ; 比较
}
```

### 注意事项

1. **运算符方法必须是成员函数**：不能是独立函数
2. **参数必须是 `Self&`**：二元运算符方法的形参类型固定为 `Self&`（接收者类型的借用）；写成按值的 `Self` 不会被运算符触发，只是普通方法。这样既避免按值复制成本，也与 `$` 接收者形态一致
3. **运算符位置自动取址**：`a == b` 编译期重写为 `a.eq(&b)`，调用方无需写 `&`；这是仅在运算符位置生效的局部例外
4. **返回值类型**：算术运算符通常返回同类型，比较运算符返回 `bool`
5. **内置类型也支持**：内置类型（如 `i32`、`f64` 等）也定义了这些运算符方法，但由编译器内部实现（标记为 `#Builtin`）

## 静态函数 `#Static` 与 `Type::name(...)`

除"构造函数 / 实例方法"两类成员外，方法块内**还可以**写**静态函数**（关联函数）。静态函数没有接收者 `$`，挂在类型命名空间下，调用语法 `Type::name(...)`。规范见 §7.10。

### 声明

注解 `#Static` 紧贴 `fn` 头；体内可以写 `Self` 类型字面量与 `Self { ... }` 字段字面量：

```yux
struct Point {
  x i32
  y i32
}

Point {
  #Static
  fn make(x i32, y i32) Point {
    ret Self {
      .x = x
      .y = y
    }
  }

  #Static
  fn origin() Point {
    ret Self {
      .x = 0
      .y = 0
    }
  }

  fn sum() i32 = $.x + $.y
}

fn main() {
  let p Point = Point::make(3i32, 4i32)
  let o Point = Point::origin()
}
```

要点：

1. **没有 `$`**：体内不能写 `$` / `$.field`，否则报 `E3128`；想访问接收者类型用 `Self`。
2. **`Self { ... }` / `<Type> { ... }` 是低层构造原语**：`.field = expr` 多行写法、无逗号；字段必须列全（不写的字段不存在默认值）。`Self { ... }` 仅 struct body 内可用；`<Type> { ... }`（如 `Point { .x = 1 .y = 2 }`）可在任意 expr 位置出现（普通 fn body、全局 `#Cval` RHS、`#Const fn` body、嵌套字面量等）。
3. **`Type::name` 调用语法**：与 `enum::variant` 共用 token `::`；编译器按 LHS 类型自动分流。
4. **与同名实例方法共存允许**：调用形态 `Type::name` 与 `obj.name` 天然区分；与同名构造函数（即与结构体同名）冲突，禁止。

### `Self` 类型字面量

`Self` 是保留字，在方法块内绑定为所属结构体类型。允许位置：fn 返回类型、形参类型、局部 `let` 类型、turbofish 实参、`Self::name(...)` 调用 LHS、`Self { ... }` 字段字面量 LHS。**字段类型位禁用** `Self`（自引用须 `Rc<Self>?` / `Weak<Self>?`）。

### 与旧构造函数的区别

> **同名构造函数已删除**（v0.14）：`fn StructName(...)` 形态不再被接受。构造通道：`#Static fn` 工厂（`Type::make(...)`）或 struct 字面量 `<Type> { .field = expr ... }`（可在任意 expr 位置直接构造）。

| 写法 | 说明 |
|---|---|
| `#Static fn name(...) Self { ret Self { ... } }` | 静态工厂；可有多个，命名自定 |
| `<Type> { .f1 = e1 .f2 = e2 }` | struct 字面量直接构造（任意 expr 位置，含 `#Static fn` 内 `Self { ... }`） |
| ~~`fn StructName(...)`（旧 ctor）~~ | 已删除，编译报错 |

SDK 已落地的工厂示例：`String::empty()` / `String::from(buf Array<u32>)` / `Rc:<T>(...)`。

## 静态字段 `#Static`

除静态函数外，结构体还可以声明**静态字段**——关联于类型而非实例的字段，通过 `Type::FIELD` 读写。规范见 §7.11。

### 声明

静态字段写在 struct body 内字段段（与实例字段混合书写），注解 `#Static` 顶行 + `NAME Type = expr`（无 `let` 关键字，与实例字段一致）：

```yux
struct Counter {
  value i32                       ; 实例字段

  ; 静态 val 字段（默认浅不可变）
  #Static
  DEFAULT_STEP i32 = 1

  ; 静态可变字段（#Mut + #Static 组合）
  #Mut
  #Static
  total_created i64 = 0

  fn inc() {
    $.value = $.value + Counter::DEFAULT_STEP
    Counter::total_created = Counter::total_created + 1
  }
}

fn main() {
  let c Counter = Counter::make(0)
  c.inc()
  println(Counter::total_created)  ; 1
}
```

要点：

1. **静态字段无 `let`**：与实例字段 `name Type` 约定一致，直接 `#Static\nNAME Type = expr`
2. **必须带初值**：v1 静态字段必须在声明处初始化（`E3150`）
3. **可变需叠加 `#Mut`**：默认浅不可变；要写在 `#Static` 前加一行 `#Mut`
4. **初始化时机**：与全局变量一致——const-evaluable → 编译期常量；否则走 `_yux_global_init` 运行期初始化
5. **泛型 struct 禁**：v1 不支持泛型 struct 上的静态字段（`E3157`）

### 读写路径

| 操作 | 语法 | 说明 |
|---|---|---|
| 读 | `Type::FIELD` | 与静态函数调用 `Type::name(args)` 共用 `::` token，编译器自动分流 |
| 写 | `Type::FIELD = expr` | 仅 `#Mut` 静态字段允许（非 `#Mut` → `E3151`） |
| 实例访问 | `obj.FIELD` | 不允许——静态字段不挂在实例上 |

### 与实例字段对照

| 维度 | 实例字段 | 静态字段 |
|---|---|---|
| 声明 | `name Type` | `#Static` 顶行 + `name Type = expr` |
| 所属 | 实例 | 类型 |
| 初始化 | `Self { .f = v }` 字段字面量 | 声明处 `= expr`（必须） |
| 读取 | `obj.field` / `$.field` | `Type::FIELD` |
| 写入 | `obj.field = v` / `$.field = v` | `Type::FIELD = v`（需 `#Mut`） |
