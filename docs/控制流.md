# 控制流

本文档介绍 yux 语言中的控制流语句。

## if/elif/else

### 作为表达式

```yux
let max = if a > b {
  a
} else {
  b
}
```

### 带有 elif

```yux
let grade = if score >= 90 {
  1
} elif score >= 80 {
  2
} elif score >= 70 {
  3
} else {
  4
}
```

### 作为语句

```yux
if x > 0 {
  println(x)
}
```

**说明：** `if` 作为语句时无需任何尾随 `;`。`;` 仅在控制转移关键字（`break;` / `continue;` / `ret;`）后表示"空返回"。

## 单行 if-else 表达式

```yux
let max = if a > b { a } else { b }
let sign = if x >= 0 { 1 } else { -1 }
```

**语法规则：**
- `if 条件 { 真值 } else { 假值 }`
- 条件、真值、假值两边必须有空格
- 真值和假值类型必须一致

## loop 循环

### 无限循环

```yux
loop {
  if cond {
    break;
  }
}
```

**说明：**
- `break;` 必须尾随 `;` 表示空返回
- `loop` 是无限循环，需要通过 `break` 退出

### 带 init 子句

`loop name = expr { }` 声明一个 loop 局部变量，默认可变，作用域为整个 loop 体：

```yux
loop i = 0 {
  if i >= 10 {
    break;
  }
  println(i)
  i = i + 1
}
```

支持类型标注：

```yux
loop i i64 = 0 {
  ...
}
```

支持 tuple 解构声明多个变量（元素类型需一致）：

```yux
loop (i, n) = (0, 10) {
  if i >= n {
    break;
  }
  i = i + 1
}
```

**说明：**
- init 变量默认可变，无需 `#Mut`
- init 变量的作用域为 loop 体，不污染外层
- 需要不可变绑定时，在 loop 前使用普通 `let`

## 循环中的 break

```yux
#Mut let sum i32 = 0
loop i = 1 {
  if i > 100 {
    break;
  }
  sum = sum + i
  i = i + 1
}
```

## Labeled loop（标签循环）

循环可以用 `label:` 前缀命名，配合 `break@label;` 从嵌套循环中跳出指定层：

```yux
outer: loop {
    inner: loop {
        if cond {
            break@outer;
        }
        break;
    }
}
```

**语法规则：**
- `label: loop` — ID 后跟 `:`，紧接 `loop` 关键字
- label 可和 loop init 组合：`outer: loop i = 0 { }`
- label 名在外层作用域中必须唯一，与外层 loop label 重名时报错 **E3022**（`Duplicate loop label '{}': already used by an enclosing loop`）
- 无 label 的 `break;` 仍跳出最内层 loop，行为不变

### break@label

```yux
break@label;
```

跳出指定标签的循环。如果标签不存在，编译报错 **E3025**（`break@label '{}' target not found: no enclosing loop with that label`）。

语法与 `break;` 一致，强制尾随 `;`。
