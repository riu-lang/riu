# 控制流

本文档介绍 yux 语言中的控制流语句。

## if/elif/else

### 作为表达式

```yux
val max = if a > b {
  a
} else {
  b
}
```

### 带有 elif

```yux
val grade = if score >= 90 {
  1
} elif score >= 80 {
  2
} elif score >= 70 {
  3
} else {
  4
}
```

### 作为语句

```yux
if x > 0 {
  println(x)
}
```

**说明：** `if` 作为语句时无需任何尾随 `;`。`;` 仅在控制转移关键字（`break;` / `continue;` / `ret;`）后表示"空返回"。

## 单行 if-else 表达式

```yux
val max = if a > b { a } else { b }
val sign = if x >= 0 { 1 } else { -1 }
```

**语法规则：**
- `if 条件 { 真值 } else { 假值 }`
- 条件、真值、假值两边必须有空格
- 真值和假值类型必须一致

## Python 风格三元表达式

```yux
val max = a if a > b else b
val sign = 1 if x >= 0 else -1
val msg = "positive" if x > 0 else "non-positive"
```

**语法规则：**
- `真值 if 条件 else 假值`
- `if` 和 `else` 两边必须有空格
- 真值和假值类型必须一致

## loop 循环

```yux
var i i32 = 0
loop {
  if i >= 10 {
    break;
  }
  println(i)
  i = i + 1
}
```

**说明：**
- `break;` 必须尾随 `;` 表示空返回
- `loop` 是无限循环，需要通过 `break` 退出

## 循环中的 break

```yux
var sum i32 = 0
var i i32 = 1
loop {
  if i > 100 {
    break;
  }
  sum = sum + i
  i = i + 1
}
```
