# 模块系统

本文档介绍 yux 语言的模块系统。

## 导入模块

```yux
; 导入特定模块
use pkg1.pkg2.some

; 导入模块所有公开成员
use pkg1.*

; 导入示例
use yux.core.*
use utils.helper
use math
```

## 模块解析规则

`use a.b.c` 映射到：
- `<projectRoot>/a/b/c.yux`（文件）
- `<projectRoot>/a/b/c/`（包目录）

**注意：** 同名 `.yux` 与同名目录并存属冲突。

## 项目配置

项目根由 `yux.toml` 标记：

```toml
name = "test"
entry = "main.yux"
version = "1.0.0"
```

### 字段说明

| 字段 | 说明 |
|------|------|
| `name` | 项目 / 可执行文件名 |
| `entry` | 入口源文件，相对项目根 |
| `version` | 版本号 |

## 项目模式

项目模式必须在 `yux.toml` 所在目录执行：

```powershell
yux build            ; 等价于 yux build <toml-name>
yux build <name>     ; 显式给出时必须与 toml 的 name 匹配
```

`<name>` 可省略；显式给出时必须与 toml 的 `name` 匹配（用作防误编译的校验）。

产物落在 `<projectRoot>/build/<name>/<name>.exe`。

## 单文件模式（已弃用）

单文件模式忽略 `yux.toml`，产物扁平放在源文件目录：

```powershell
yux input.yux
```

**注意：** 单文件模式已弃用，新增代码、示例、文档一律走项目模式。

## 项目结构示例

```
myproject/
├── yux.toml
├── main.yux
├── utils/
│   ├── helper.yux
│   └── math.yux
└── build/
    └── myproject/
        └── myproject.exe
```

## 私有模块

以 `_` 开头的模块成员为私有，仅在当前模块可见：

```yux
; 私有函数
fn _internal_helper() {
}

; 私有全局常量
cval _MAX_RETRIES i32 = 3
```
