# 第一个程序

Windows，且 `yux` 已在 PATH（见 [安装指南](安装指南.md)）。

## Hello World

```
hello/
├── yux.toml
└── src/
    └── main.yux
```

**yux.toml**：

```toml
name = "hello"
version = "1.0.0"
entry = "main.yux"
```

`entry` 相对源根：存在 `src/` 时源根是 `src/`，所以入口文件是 `src/main.yux`。

**src/main.yux**：

```yux
fn main() {
  println("Hello, World!")
}
```

```powershell
cd hello
yux build
./build/hello.exe
```

`yux build` 可省略项目名；写了则必须与 `yux.toml` 的 `name` 一致。

## 最小 CLI

仓库 [examples/](../examples/) 里有不写 C 的小程序。

### 参数：echo

`args()` 返回 `Array<String>`，`[0]` 是 exe 路径，用户参数从 `[1]` 起。

```powershell
cd examples/echo
yux build
./build/echo.exe hello world
```

### 读文件：cat

须 `use yux.io.*`（或 `use yux.io` 后写 `io.read_file`）。失败走 `T ! IoErr`，未处理时用 `exit(1)`。

```powershell
cd examples/cat
yux build
./build/cat.exe 某个.txt
```

### 交互：guess

`read_line()` 读 stdin 一行；`String.parse_i32()` 把十进制收成 `i32?`（非法为 `null`）。

```powershell
cd examples/guess
yux build
./build/guess.exe
```

### 列目录：ls

`cwd()` 当前目录；`list_dir` 列出名字（不含 `.` / `..`）。缺路径时 `exists` 为 false。

```powershell
cd examples/ls
yux build
./build/ls.exe
./build/ls.exe 某个目录
```

### 链接：wln

`symlink` / `hardlink` / `junction`；目录软链没权限时自动改 junction。`-f` / `-y` / `-n` 对齐原 `wln`。

```powershell
cd examples/wln
yux build
./build/wln.exe --help
./build/wln.exe 某个文件或目录
```
