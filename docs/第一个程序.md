# 第一个程序

Windows，且 `riu` 已在 PATH（见 [安装指南](安装指南.md)）。

## Hello World

```
hello/
├── riu.toml
└── src/
    └── main.ut
```

**riu.toml**：

```toml
name = "hello"
version = "1.0.0"

[[executable]]
entry = "main.ut"
```

`entry` 写在 `[[executable]]` 上，相对源根：存在 `src/` 时源根是 `src/`，所以入口文件是 `src/main.ut`。

`println` 来自隐式 `riu.core`，hello-world **不必**写 `[dependencies]`。要用 `riu.io` / `riu.time` 时在 toml 加：

```toml
[dependencies]
stdlib = { sdk = "stdlib" }
```


**src/main.ut**：

```riu
fn main() {
  println("Hello, World!")
}
```

```powershell
cd hello
riu build
./build/hello.exe
```

`riu build` 可省略名字（编全部产物）。写出则按产出名命中；单 exe 且未写产物 `name` 时，产出名就是项目 `name`，`riu build hello` 仍可用。

## 最小 CLI

仓库 [examples/](../examples/) 里有不写 C 的小程序。

### 参数：echo

`args()` 返回 `Array<String>`，`[0]` 是 exe 路径，用户参数从 `[1]` 起。

```powershell
cd examples/echo
riu build
./build/echo.exe hello world
```

### 读文件：cat

须 `use riu.io.*`（或 `use riu.io` 后写 `io.read_file`），且 toml 声明 `stdlib = { sdk = "stdlib" }`。失败走 `T ! IoErr`，未处理时用 `exit(1)`。

```powershell
cd examples/cat
riu build
./build/cat.exe 某个.txt
```

### 交互：guess

`read_line()` 读 stdin 一行；`String.parse_i32()` 把十进制收成 `i32?`（非法为 `null`）。

```powershell
cd examples/guess
riu build
./build/guess.exe
```

### 列目录：ls

`cwd()` 当前目录；`list_dir` 列出名字（不含 `.` / `..`）。缺路径时 `exists` 为 false。

```powershell
cd examples/ls
riu build
./build/ls.exe
./build/ls.exe 某个目录
```

### 目录树：tree

`File.list()` 递归；软链只打印、不往下走。缺路径时默认 `cwd`。

```powershell
cd examples/tree
riu build
./build/tree.exe
./build/tree.exe 某个目录
```

### 搜行：grep

`String.contains`；`-i` 先 `to_lower`。无文件时读 stdin。`a[i]` 是 `String&`，要拿走一份写 `copy_of(a[i])`。

```powershell
cd examples/grep
riu build
./build/grep.exe hello 某个.txt
./build/grep.exe -i hello 某个.txt
```

### 计数：wc / freq

`wc` 扫码点计行 / 词 / UTF-8 字节。`freq` 把词放进 `Map<String, i32>`，再 `sort_by` 按次数降序。

```powershell
cd examples/wc
riu build
./build/wc.exe 某个.txt

cd ../freq
riu build
./build/freq.exe 某个.txt
```

### 链接：wln

`symlink` / `hardlink` / `junction`；目录软链没权限时自动改 junction。`-f` / `-y` / `-n` 对齐原 `wln`。

```powershell
cd examples/wln
riu build
./build/wln.exe --help
./build/wln.exe 某个文件或目录
```
