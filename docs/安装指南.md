# 安装指南

本文档介绍 riu 编译器的安装和环境配置。

## 环境要求

- **操作系统**：Windows
- **编译器**：Clang
- **构建工具**：GN（PATH）；Ninja 由 `./sync-deps.ps1` 下载到 `bin/`（也可在 PATH）
- **依赖**：LLVM 工具链（在 PATH 中）

## 安装方式一：预编译包（推荐）

从 [Releases](https://github.com/riu-lang/riu/releases) 下载 `riu-<version>.zip`，解压到任意目录，将 `bin/` 加入 PATH。

```
riu/
├── bin/
│   ├── riu.exe
│   ├── riu-lsp.exe
│   ├── riu-check.exe
│   ├── riu-ast.exe
│   └── riu-test-runner.exe
├── lib/
│   └── riurt.lib
├── sdk/
├── docs/
├── examples/
├── README.md
└── LICENSE.txt
```

```powershell
# 验证安装
riu --version
```

预编译包通过 `./build.ps1 pack` 生成，仅包含当前构建 profile（debug 或 release）的二进制。

## 安装方式二：从源码构建

### 1. 克隆仓库

### 2. 同步依赖

```powershell
./sync-deps.ps1
```

若 `llvm` 有更新，下一步构建会自动重配并编译 LLVM（可能较久）。

### 3. 构建编译器

```powershell
./build.ps1 riu
```

### 4. 配置环境变量

将 `build/windows/x64/debug/bin` 添加到 PATH 环境变量，以便直接调用 `riu` 命令。

## 验证安装

构建完成后，可以验证编译器是否正常工作：

```powershell
riu --version
```

## 快速开始

见 [第一个程序](第一个程序.md)（`riu.toml` → `riu build` → 跑 exe；以及 echo / cat / guess）。

### 创建项目

创建项目目录结构：

```
myproject/
├── riu.toml
└── main.ut
```

**riu.toml**：

```toml
name="hello"
version="1.0.0"
entry="main.ut"
```

**main.ut**：

```riu
fn main() {
  println("Hello, World!")
}
```

### 编译运行

**目录布局**：源文件放在 `<projectRoot>/src/` 下，`entry` 字段相对源根。

```
myproject/
├── riu.toml
└── src/
    └── main.ut
```

```powershell
cd myproject
riu build              ; 等价于 riu build hello
./build/hello.exe
```

## 编译命令

`<name>` 可省略，省略时取 `riu.toml` 中的 `name`；显式给出则必须与之一致。

| 命令 | 说明 |
|------|------|
| `riu build [<name>]` | 项目模式编译 |
| `riu build [<name>] --emit-ir` | 输出 LLVM IR |
| `riu build [<name>] --emit-ir-dir <dir>` | IR 输出到指定目录（默认 build/） |
| `riu build [<name>] -d` | 调试模式 |

## 辅助工具

随主编译器一起构建的独立可执行文件，安装时与 `riu.exe` 放在同一目录（`bin/`）。

### `riu-ast`

转储 rd 词法 token 或 FlatAst 树，仅词法 + 语法分析，不构造 FileNode、不做语义检查、不调用 LLVM。

```powershell
./build.ps1 riu-ast              ; 单独构建（首次使用前）

riu-ast <input.ut>              ; FlatAst 打印到 stdout（默认 --rd）
riu-ast <input.ut> -o <file>    ; 写入文件
riu-ast <input.ut> --rd-tokens  ; 词法 token
```

### `riu-check`

单文件快速语义检查（阶段 0），不依赖 LLVM，适合 CI 诊断回归测试。

```powershell
./build.ps1 riu-check            ; 单独构建（首次使用前）

riu-check <file.ut>             ; 单文件诊断
riu-check test tests/check-cases/ -r  ; 批量诊断测试
```

### `riu-lsp`

LSP 服务器，供编辑器插件（VSCode / IntelliJ / Claude Code）通过 stdio 接入；通常由插件自动启动，无需手工调用。

### `riu-test-runner`

测试运行器，由 `riu test` 内部调用，一般不需要手动使用。

## 常见问题

### 1. 找不到 riu 命令

确保 `build/windows/x64/debug/bin` 已在 PATH 中，或者使用完整路径调用。

### 2. 依赖同步失败

检查网络连接，确保可以访问外部仓库。

### 3. 构建失败

确保已安装 Clang、GN，且 LLVM 工具链在 PATH 中；Ninja 经 `./sync-deps.ps1` 放入 `bin/`。
