# 安装指南

本文档介绍 yux 编译器的安装和环境配置。

## 环境要求

- **操作系统**：Windows
- **编译器**：Clang
- **构建工具**：xmake
- **依赖**：LLVM 工具链（在 PATH 中）

## 安装步骤

### 1. 克隆仓库

### 2. 同步依赖

```powershell
./sync-deps.ps1
```

### 3. 构建编译器

```powershell
xmake build yux
```

### 4. 配置环境变量

将 `build/windows/x64/debug/bin` 添加到 PATH 环境变量，以便直接调用 `yux` 命令。

## 验证安装

构建完成后，可以验证编译器是否正常工作：

```powershell
yux --version
```

## 快速开始

### 创建项目

创建项目目录结构：

```
myproject/
├── yux.toml
└── main.yux
```

**yux.toml**：

```toml
name="hello"
version="1.0.0"
entry="main.yux"
```

**main.yux**：

```yux
fn main() {
  println("Hello, World!")
}
```

### 编译运行

**目录布局**：源文件放在 `<projectRoot>/src/` 下，`entry` 字段相对源根。

```
myproject/
├── yux.toml
└── src/
    └── main.yux
```

```powershell
cd myproject
yux build              ; 等价于 yux build hello
./build/hello.exe
```

## 编译命令

`<name>` 可省略，省略时取 `yux.toml` 中的 `name`；显式给出则必须与之一致。

| 命令 | 说明 |
|------|------|
| `yux build [<name>]` | 项目模式编译 |
| `yux build [<name>] --emit-ir` | 输出 LLVM IR |
| `yux build [<name>] --emit-ir-dir <dir>` | IR 输出到指定目录（默认 build/） |
| `yux build [<name>] -d` | 调试模式 |

## 辅助工具

随主编译器一起构建的独立可执行文件，安装时与 `yux.exe` 放在同一目录（`build/windows/x64/<mode>/bin/`）。

### `yux-ast`

转储 ANTLR4 parse tree，仅词法 + 语法分析，不构造 AST、不做语义检查、不调用 LLVM。
即使源文件存在语法错误也照样输出（含 `<error>` 节点的）树。

```powershell
xmake build yux-ast              ; 单独构建（首次使用前）

yux-ast <input.yux>              ; 多行 pretty 树打印到 stdout
yux-ast <input.yux> -o <file>    ; 写入文件
yux-ast <input.yux> --oneline    ; 单行紧凑形式
```

### `yux-lsp`

LSP 服务器，供编辑器插件（VSCode / IntelliJ / Claude Code）通过 stdio 接入；通常由插件自动启动，无需手工调用。

## 常见问题

### 1. 找不到 yux 命令

确保 `build/windows/x64/debug/bin` 已在 PATH 中，或者使用完整路径调用。

### 2. 依赖同步失败

检查网络连接，确保可以访问外部仓库。

### 3. 构建失败

确保已安装 Clang 和 xmake，且 LLVM 工具链在 PATH 中。
