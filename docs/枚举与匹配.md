# 枚举与匹配

本文档介绍 yux 语言中的 `enum` 与 `match`。规范层定义见 [docs/spec/03-类型系统.md §3.10](spec/03-类型系统.md#310-枚举enum)，形态决议日志见 [docs/spec/draft/DRAFT-枚举.md](spec/draft/DRAFT-枚举.md)。

## 概览

`enum` 表达"对象处于若干互斥状态之一"。每个状态称为一个 **variant**，可选携带一组按位置排列的数据（**payload**）。读取 enum 值的唯一稳定通道是 `match` 表达式。

```yux
enum Shape {
  Point
  Circle(f64)
  Rect(f64, f64)
}

fn area(s Shape) f64 = match s {
  Shape::Point => 0.0
  Shape::Circle(r) => 3.14 * r * r
  Shape::Rect(w, h) => w * h
}
```

## 声明枚举

```yux
enum Color {
  Red
  Green
  Blue
}

enum Shape {
  Point              ; 零参 variant
  Circle(f64)        ; 单元素 tuple payload
  Rect(f64, f64)     ; 多元素 tuple payload
}
```

约定：

- variant **一行一个**，行尾**不写** `,`。
- variant 名采用 PascalCase（与类型名同规约）。
- 同一 enum 内 variant 名不得重复。
- payload 元素类型与"普通类型出现位置"一致：基础类型、`struct`、`Box<T>` / `Array<T>` / `String`、`T?`、tuple、类型别名等都可以；**不能**出现 `T&`。
- 空 enum（无 variant）会编译期拒绝；单 variant 合法（占位用）。

## 构造枚举值

```yux
val a = Color::Red                    ; 零参 variant
val b = Color::Red()                  ; 与上等价

val c = Shape::Circle(1.5)            ; 带 payload
val d = Shape::Rect(3.0, 4.0)
```

要点：

- variant **永远全限定**为 `E::V`，不能省略 `E::`。
- 零参 variant 写带不带括号编译器一视同仁。
- 带 payload 时，实参个数与类型严格匹配 variant 声明（**无隐式转换**）。

类型别名透明传递：

```yux
type C = Color
val x = C::Red          ; 等价于 Color::Red
```

## match 表达式

```yux
val area = match s {
  Shape::Point => 0.0
  Shape::Circle(r) => 3.14 * r * r
  Shape::Rect(w, h) => w * h
}
```

约定：

- 箭头一律 `=>`（`->` 留给后续 lambda）。
- arm **一行一个**，行尾**不写** `,`。
- arm 顺序对穷尽语义无影响；唯一例外是 `else`，必须放最后一条。
- match 是**表达式**：所有 arm 体类型应当严格一致（无隐式转换）。
- v1 中 arm body 仅支持单表达式；多语句体押后。

### 模式形态（v1）

| 模式 | 含义 |
|---|---|
| `E::V` | 匹配零参 variant |
| `E::V()` | 与 `E::V` 等价 |
| `E::V(name1, name2)` | 匹配 tuple-payload variant，按位置绑定到名字 |
| `else` | 兜底分支，匹配尚未显式列出的所有 variant |

绑定规则：

- 绑定名是普通标识符；同一模式内不得重复。
- 绑定为不可变值绑定（不能再赋值），作用域为该 arm 体。
- 绑定的类型为对应 payload 元素的类型。

### 穷尽性

编译器强制穷尽性检查，下面两种形态合法：

1. **显式列全所有 variant**：

   ```yux
   match c {
     Color::Red => "red"
     Color::Green => "green"
     Color::Blue => "blue"
   }
   ```

2. **任意子集 + `else` 兜底**：

   ```yux
   match s {
     Shape::Point => "no area"
     else => "has area"
   }
   ```

漏掉 variant 且无 `else` 会报 `E2023`，重复 variant 报 `E2024`，`else` 不在末尾报 `E2025`。

### 含 RC payload 的绑定

payload 含 `String` / `Box<T>` / `Array<T>` 等 RC 类型时，binding 是**借用**：

```yux
enum Msg {
  Hello(String)
  Bye
}

fn greet(m Msg&) {
  match m {
    Msg::Hello(name) => println("hello $name")
    Msg::Bye => println("bye")
  }
}
```

`name` 仅在 arm body 内有效，arm 退出时不会触发额外 release。把 binding 直接作为 match 结果返回时，`Box` / `Array` / `Weak` 走归一；含 String 等其它 RC 类型时**应当**先用 binding 间接计算 POD 后再返回（v1 限制）。

## v1 不支持

- 泛型 enum `enum E<T> { ... }`
- enum 上的方法 / 独立 `impl` 块 / draft 实现
- struct-style payload `V { f: T }`
- 显式 discriminant `Red = 1` / `as i32`（tag 是实现细节，不暴露）
- `_` 通配（任意位置）—— 走 `else` 兜底
- 字面量模式 / 嵌套模式 / 范围模式 / 守卫 `if` / `|` 多模式 / `@` 绑定
- 整型 / 字符串 match
- 跨文件 / 跨模块追加 variant（enum 是封闭的）

## 与其它类型的搭配

- `Box<E>`：把 enum 上堆，按现有 Box 协议 retain / release，析构时按 tag dispatch。
- `Array<E>`：元素按值存储；析构遍历元素 dispatch drop。
- `E?`：按现有 Nullable 规则展开，可空 enum 句柄。

## 完整示例

```yux
enum Result {
  Ok(i32)
  Err(String)
}

fn divide(a i32, b i32) Result {
  if b == 0 {
    Result::Err("division by zero")
  } else {
    Result::Ok(a / b)
  }
}

fn main() {
  val r = divide(10, 3)
  match r {
    Result::Ok(v) => println("ok: ${v.to_string()}")
    Result::Err(msg) => println("err: $msg")
  }
}
```
