# v0.22.0

✅ 2026-09-13。主题：SDK 完善 + pkg 可见性收口。

## 范围（当时预提交）

- 有 `pkg` 时包外只走清单；`to` 定向开放；同目录兄弟为包内；`name.*` 只扁平公开
- SDK 公开面与清单对齐；内部 Win32 进 `helper to yux.io`
- 补 String / Array / Map / IO / 路径 / 环境；`Array[i].method()` 按元素类型分派

pkg 实施过程：`docs/dev/pkg-export-impl-log.md`。spec 条款 diff：`docs/spec/CHANGELOG.md` 2026-09-06～13。

## 加

- **pkg**：包边界 / `to` / E5018–E5020；SDK 壳只扁平公开 `name.*`
- **语言**：`<>` 内 `T&` 迁语义；合并 `type`/`typeWithRef`；声明头 / 返回再收紧（E4037–E4040）；单字段 `Type{ expr }`；位运算改 `and`/`or`/`xor`/`shl`/`shr`/`inv`；整数字面量越界 E3103；静态 fallible `Type::fn()!`
- **SDK**：String 切片 / 查找 / 解析 / `Ord` / `from_bytes` / 浮点 parse；Array 查询改位、急切 `any`/`all`/`filter`/`map`、`swap`/`sort`；`Set` + Map `get_or`；`StringBuilder` 标量 `append`；`Number` spec；`yux.io` Path/File/流 / 链接 / 字节 IO / `io_err_text` / 环境与目录；独立包 `yux.time`
- **示例**：`ls`；`wln` 改对象 API

## 修

- 下标后方法按元素 `T&` 分派
- `T?` 字段赋值与跨模块包装返回（`string_nullable_cross_return`）
- Array 深拷 / 闭包逃逸 / 元素析构泄漏
- 对象返回所有权；`let` fallible Array 失败路径
- `#NoReturn` 臂不参与类型合并
- 泛型实例体按 `enclosingFile` 解析包别名
- 方法 `T&` ABI 与 try/catch 临时帧
- SemaPass 接管 LLVM 布局诊断
- 通配查找不再再导出 `use` 注入的符号
