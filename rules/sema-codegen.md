# Sema / Codegen

目标：`yux-check` 独立、0 LLVM，诊断与 `yux build` 等价。当前半完成。

- `yux/frontend/sema/`（`sema_pass` / `call_resolve`，库 `yux_frontend`）禁止 LLVM、`IRBuilder`、`_module`。
- 新 `throw YuxError` 默认写 Compiler。`getType()` 的 YuxError 由 SemaPass **默认重抛**；必须暂留 Compiler 的码加入 `kDeferredCodes`（当前为空），禁止静默吞。方法点 callee 的 E3095：`visitExpr` 先按形态记下（挡住 E1101/E1140），Dot 分支校验 `@Spec` 后——字段非 Fn 值直接报，其余延迟重抛。ID-literal 的 E3095 立即重抛。sema 已覆盖的 Compiler throw / validate **删掉**，不双跑；codegen 若仍走到该路径用 `throwSemaGap`（E3091），不再抛原语义码。
- 泛型 fn/impl 体已走 SemaPass：类型参数当不透明 TypeParam。形态检查（#NoCopy / 未定义符号 / arity / 已知 struct 缺字段 / 索引赋值非 lvalue / `<-` LHS E4036 / 方法当值 E3090 / T& 拷绑非本帧 E4004 / 未知 `#Builtin` E6017 / `Self::name` 体外 E3123 / 缺 `#Static` E3121 / 实例方法当静态 E3120 / 数组填充非 int·float·bool 字面量 E3080）在模板体报；ret / 赋值 / 方法分派 / 内置运算符 / 一元运算符 / 索引 / 成员链 / `?.` / `??` / match / if 分支 / 字符串插值与 `String +` / 比较形态 / `&&`·`||` / lambda 捕获 / 空数组字面量 / 嵌套泛型推断 / `Field.value` / `Struct::variants` / `assert_eq` / `same_ref`·`ptr_of`·`as_ref`·`weak` 在调用点或写出的 `S<Concrete>` 类型位置 `substitute` 后再查（E3014 / E3095 / E3090 / E3001 / E3005 / E3070 / E3071 / E3074 / E3060 / E3061 / E3062 / E3063 / E3080 / E3040 / E3041 / E3044 / E3152 / E3024 / E2022 / E3026 / E3078 / E3073 / E2029 / E3133 / E3134 / E3135 / E6030 / E6031 / E4004 / E4036 / E3120 / E3121 / E3123 / E6012 / E6013 / E6028 / E6029）。
- 数组 / 元组字面量：`visitExpr` 带 target-type（声明 / 赋值 / 返回 / 调用实参 / 字段 / if·match·try 块末尾 / 嵌套），E3009 / E3012 / E3063 由 SemaPass 抛。数组填充 `[v ...]`：fill 须是 int / float / bool 字面量，否则 E3080（string / null / 码点 / 变量；与 T 无关的形态模板期也报；类型不符仍先 E3009）。
- 调用实参：唯一 arity 非泛型候选（及 Fn 值 / 非泛型方法 / `#Static fn`）在重载前带形参类型下钻；同 arity 重载只对各位都相同的类型下钻，不一致的位置不猜。泛型 fn 显式 typeArgs（及推断完成后）按 `TypeInfo::substitute` 后的形参下钻 / E3014；无显式 typeArgs 时 infer 失败 → E6012（arity）/ E6013（无法反推），调用点与实例化后重抛；泛型 fn 类型实参个数 → E6010；泛型 struct `#Static` turbofish 类型实参个数 → E6011（无 turbofish 仍 skip）；非泛型 struct 写 `Type:<T>::name` → E6011（expects 0）；值实参 → E3131；`Self::name(...)` 在 struct body 内等同当前类型名（体外 E3123；缺 `#Static` E3121 / 实例方法 E3120；泛型实例化后无 turbofish 绑当前单态）；接收者已带 typeArgs 的实例方法同款。`assert_eq` / `assert_true` / `assert_false` / `fail` 实参个数 → E6027。Builtin 泛型 intrinsic：显式 typeArgs 或推断后查形态（`same_ref` / `ptr_of` E6028 / E6029，`as_ref` / `weak` E6029，未知名 E6017）；`as_ref(Heap<T>)` 抽内层（unify 对不上 Rc<T>）。赋值 LHS 根未定义 → E3030（`obj` 不是表达式）。运算符方法歧义 → E6014。
- lambda：`expected` 为 Fn 时 `setInferredFnType` + bodyScope 形参回填（声明 / 上述调用点）；表达式体带返回类型下钻并做 E3014；块体 `ret` / 末位无 `;` 的尾表达式按 lambda 标注或反推返回类型检查，不用外层 fn。捕获：subst 后须是标量 / 堆句柄 / T& / Heap?，否则 E2029；T& 与堆句柄混捕 → E2029（模板形参跳过；与 T 无关的不支持类型模板期也报）。E2028 为 Compiler 捕获通路未启的兜底，sema 不报。泛型 callee 的实参 lambda（含尾随）在 typeArgs 替换后再 `emitLambdaFunction`，勿用未替换的 `Function<T,...>`。
- `ret`：Fallible 成功/错误双通道、T& 内层类型、Nullable wrap、别名 `resolveAlias`、灵活整数推断 → E3014。非法 T& 源形态由 analyzer E4001/E4020 先报。T& 局部 `&expr` 内层 E3014。
- 赋值：RHS 相对存储槽 E3014。T& 局部 / `$`（Self&）store-through 比内层 T；Nullable wrap / Rc wrap / 灵活整数与 codegen 对齐。索引赋值同款。经 T& / `$` 的嵌套数组走靶向类型 E3009。索引读 / 索引赋值：subst + peelRef 后非 `[N]T` / `Array<T>` → E3062（模板形参跳过）。索引赋值另查形态：空下标 E3060（g4 死防御）；基须是变量或单层 `obj.field`，否则 E3061（与 T 无关的形态模板期也报；读路径不要求 lvalue）。`<-` LHS：须是变量 / `$` / 字段 / 元组 `.N`，否则 E4036（字面量 / 调用 / 索引；与 T 无关的形态模板期也报）。空 `[]`：仅 Array<T> 靶向合法，否则 E3063（无注解 / 固定数组先于 E3012；模板形参等实例化后再查；`a <- []` / `a ?? []` 分别用左侧类型、左侧 Nullable 内层当下靶）。数组填充 `[v ...]`：fill 须是 int / float / bool 字面量，否则 E3080（与 T 无关，模板期也报；类型不符仍先 E3009）。成员赋值 / `&obj.field` / 读路径 `x.foo`：subst + peelAutoDeref 后缺字段 → E3040，非 struct → E3041，实例碰静态字段 → E3152（模板形参跳过；已知 struct 缺字段模板期也报）。元组 `.N`（读 / 赋值 / `&t.N`）越界 → E3100（模板形参等实例化后再查；别名 `resolveAlias`）。方法调用 `x.foo()` 不走读路径。`?.`：subst + 剥 Ref 后非 Nullable → E3024；内层无 struct → E3044；缺字段 → E3040（方法 / `to_*` 不按字段查；模板形参跳过）。`??`：同样 subst 后左侧非 Nullable → E3024，右侧与内层不符 → E3014（模板形参跳过；右侧 `[]` 按内层靶向）。字符串模板插值与 `String +` 叶子：subst 后须是 String 或有 `<T>.to_string`，否则 E3026（模板形参跳过）。`Field.value`：运行期 Field → E3133；无 `$`（自由函数 / `#Static`）→ E3134（读 / 写 / `&f.value`；模板形参跳过）。`Struct::variants`：非 enum → E3135。读路径方法当值 / 非字段 Fn·Dyn → E3090（`to_*` 与字段型 Fn 除外；模块/包链与 `x.foo()` 调用不走）。T& 拷绑：源须是本帧 T&（形参 / 局部，与 `_localVarPtrs` 对齐）；全局或 lambda 外层 → E4004。
- 声明：`Rc<T>` 同型或内层 T 包装 → E3014；`Weak<T>` 仅 Rc<T> / Weak<T> → E3016；`Array<T>` 非 Array 表达式且非字面量 → E3064。须在 visitExpr 带靶向类型之后查（if/match 块末尾先走 E3009）。Heap 非 `heap:<T>(...)` 由 borrow checker E4024 先报。模板形参等实例化后再查。
- 元组解构（`let (a, b) = expr` / `loop (a, b) = expr`）：标注优先否则 RHS，经 subst + `resolveAlias` 后非元组 → E3101；元素数 ≠ 名字数 → E3102。模板形参 T 跳过；`Array<T>` 等永远不是元组，模板期也报。
- match：各臂结果类型一致 → E3014（流终止臂跳过）。scrut 经 subst + 别名 / Rc<E> / Heap<E> / E& 剥到 enum；临时 Rc/Heap 直接 match → E2022；非 enum（含用户 struct、实例化后的 T）→ E2022（模板形参跳过）。实例化为 enum 后走臂校验（E2019 / E2020 / E2023 等）。if / match / try 块末尾值带靶向类型（嵌套数组 E3009）。if / elif / else 与一行 `if c { a } else { b }`：subst 后分支类型须一致 → E3005（模板形参跳过；与 T 无关的不匹配模板期也报）。比较：subst + peelAutoDeref 后 Weak ==/!= → E3078，Ptr 排序 → E3073（模板形参跳过；`Weak<T>` 参数等与 T 无关的形态模板期也报）。`&&` / `||`：subst 后两侧类型须一致，内置跨类型 → E3001 comparison（模板形参跳过；与 T 无关的不匹配模板期也报）。
- 新 AST / 表达式：`SemaPass::visitExpr` 必须加分支（可 `return;`），否则整棵子树被 skip。
- 缺口：
  - 两边都不查（与未调用泛型 fn 一致）：源码从未写出 `S<Concrete>` 且无调用时，泛型 struct 方法体内依赖 T 的类型错；未调用泛型 fn 体内嵌套推断 E6012/E6013。
  - E2028 为 Compiler 捕获通路未启的兜底。
  - 已覆盖码的 Compiler 副本改为 `throwSemaGap`（E3091），不双跑。E3140 由 AST builder 抛；E3072 / E3080（全局 String `#Cval` / 未知 literal 兜底）/ E3091 / E3092 / E3096 / E3098 / E3099 / E6019 为内部或 LLVM 兜底。数组填充 E3080、`<-` LHS 形态 E4036 已由 SemaPass 做。Dyn 构造 E1131/E1132/E1133/E1134、try/catch E7002/E7011、同名 ctor E3130、容器禁令 E4025、非泛型 struct turbofish E6011、`Self::name` E3123/E3120/E3121 已由 SemaPass 做。
  - 写出 `S<Concrete>` 的类型位置（形参 / 返回 / 字段 / let / 声明 / 全局常量）由 SemaPass 复查方法体。调用点签名替换、ret / 赋值（含 LHS 未定义 E3030）、声明处 Rc / Weak / Array、元组解构（E3101 / E3102）、实例化后的方法分派 / 内置与一元运算符 / 索引（E3062）与赋值形态（E3060 / E3061）/ 空数组字面量（E3063）/ 数组填充（E3080）/ 成员链（E3040 / E3041 / E3152 / E3100，含读路径与元组 `.N`）/ 方法当值等非字段点表达式（E3090）/ `?.`（E3024 / E3044 / E3040）/ `??`（E3024 / E3014）/ match 非 enum（E2022）与实例化后的臂校验、if 分支（E3005）、字符串插值与 `String +`（E3026）、比较形态（E3078 / E3073）、`&&` / `||`（E3001）、lambda 捕获（E2029）、`Field.value`（E3133 / E3134）、`Struct::variants`（E3135）、`assert_eq`（E6030 / E6031）与断言 arity（E6027）、T& 拷绑非本帧（E4004）、泛型 struct `#Static` turbofish arity（E6011，含非泛型 struct 写 `:<T>`）、泛型 fn 类型实参个数（E6010）、运算符方法歧义（E6014）、Builtin `same_ref` / `ptr_of` / `as_ref` / `weak`（E6028 / E6029）与未知 `#Builtin`（E6017）、以及调用点 / 实例化后的 typeArgs 推断（E6012/E6013）、`<-` LHS 形态（E4036）、`Self::name`（E3123 体外 / E3120 实例方法 / E3121 缺 `#Static`）、Dyn 构造（E1131/E1132/E1133/E1134）、try/catch（E7002/E7011）、同名 ctor（E3130）已由 SemaPass 做。其余依赖 T 具体化且未在调用点实例化的路径，throw 写 Compiler。

`yux-check <file>` 是 `yux build` 报错的**子集**。
