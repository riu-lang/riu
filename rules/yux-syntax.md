# yux 语法 — 写前清单

写 `*.yux` 时**逐条过**。每条都是"不看就会写错"的硬规则，不是风格建议。
**写完必须 `yux-check <file>` 确认**。

## 写前逐条检查

```
□  1. 注释用 `;`（不是 `//` 或 `#`）？行首或 `空格 + ;` 开头？
□  2. 关键字后、二元运算符两边、`,` 后必须有空格？`()` `[]` 内部无空格？
□  3. 局部变量 `let name Type = expr`？结构体字段不加 `let`（直接 `name Type`）？
□  4. 可变变量 `#Mut` 写在 `let` 的上一行（顶行堆叠）？
□  5. 当前实例用 `$` 不是 `self` 或 `this`？`$.field` / `$.method()`？
□  6. 块 `{ }` 可单行（`fn f() { ret 1 }`）也可多行；没把无关的 struct / match 臂压成非法单行？
□  7. 单表达式体用 `= expr`（`fn foo() i32 = 42`）？`=` 和表达式在同一行？
□  8. 没用独立裸 `{ }` 语句块？同块内 `let` 不重名；if/loop 等体内可遮蔽外层？
□  9. 数组 `[T * N]` 的 N 是 INT 字面量（不能是表达式/变量/泛型参数）？
□ 10. 堆句柄 `heap:<T>(v)` / `rc:<T>(v)` 写了 `:<T>`？编译器不会从参数推导！
□ 11. 移入赋值 `a <- b`：是表达式（返回旧值），`a = b` 是语句（不产生值）？
□ 12. 没有隐式类型转换？需要时写了 `.to_<type>()`？
□ 13. 灵活整数后缀写对？不生效场景（方法参数/数组元素/泛型）加了后缀？
□ 14. 注解顶行堆叠？每个 `#Anno` 单独一行在 fn/let 上面？
□ 15. 没用 `++` / `--` / `+=` / `? :` 等 C 风格运算符？
□ 16. `&&` / `||` 是短路求值，位运算用 `and` / `or`？
```

## 灵活整数速查

| 自动推断（不加后缀也 OK） | 必须后缀 |
|---------------------------|----------|
| `let a i64 = 100` — 声明类型已知 | `arr.get(0i64)` — 方法参数重载消歧 |
| `assert_eq(a_i8, 42)` — 泛型 T 由第一实参推断 | `[10u32, 20u32]` — 数组元素类型 |
| `take_i64(100)` — 非泛型/非重载 | 泛型 fn + 非 i32：`fns_identity(100i64)` |
| `a_u8 + 1` — 运算符对侧类型已知 | `let a = 255u8` — 无类型标注 |

后缀：`42i8` `100u32` `0xFFu64` `42usize`（数字 + `i`/`u` + 位宽或 `size`）

## 标量运算符自动解引用

`+ - * / % & | ^ << >>` 和 `== != < <= > >=` 两侧操作数如果是 `T&`，自动取引用指向的值。
`Rc<T>` receiver 自动解引用找 `T` 的方法。

**不自动解引用的位置**：`let` 声明、函数实参、`ret`。
